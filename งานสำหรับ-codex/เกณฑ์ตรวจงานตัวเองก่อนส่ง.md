# เกณฑ์ตรวจงานตัวเองก่อนส่ง — ใช้กับทุกใบสั่งงาน (ฉบับที่ 2 · 7 ต.ค. 2569)

> ใบสั่งงานถาวร ไม่มีเลขรอบ **ทุกครั้งที่ทำงานเสร็จ ให้ทำตามไฟล์นี้ก่อนบอกว่าเสร็จ**
> ถ้าใบสั่งงานรายรอบขัดกับไฟล์นี้ ให้ถือใบสั่งงานรายรอบ

การตรวจตัวเองมีสองส่วน และ **ต้องทำทั้งสองส่วน**

| ส่วน | ตรวจอะไร | ทำอย่างไร |
|---|---|---|
| ก. ตรวจด้วยเครื่อง | รูปแบบ ตัวเลข ขอบเขตไฟล์ | รัน `python scripts\codex_selfcheck.py --md` แล้ววางผลในรายงาน |
| ข. ตรวจด้วยมือ | ความหมาย: คำตอบถูกไหม มีคำตอบเดียวไหม กฎมีข้อยกเว้นไหม | ทำข้อเองโดยปิดเฉลย และพยายามหักล้างงานตัวเอง |

ส่วน ก ผ่านไม่ได้แปลว่างานถูก ข้อผิดที่หลุดถึงผู้ตรวจอีกฝ่ายในรอบ 7–15 **เกือบทั้งหมดเป็นเรื่องความหมาย** ซึ่งเครื่องจับไม่ได้

## ขั้นตอน — ทำตามลำดับนี้ทุกรอบ

```powershell
cd D:\project\addmission
$env:PYTHONIOENCODING = "utf-8"

# 1) build เฉพาะวิชาที่แก้
python scripts\build_content.py tgat1      # หรือ tgat3 / tpat3

# 2) ตัวตรวจของโปรเจกต์
python scripts\validate.py
python scripts\render_template.py --stress

# 3) ตัวตรวจงานตัวเอง (อ่านอย่างเดียว ไม่แก้ไฟล์)
python scripts\codex_selfcheck.py            # ดูรายละเอียด
python scripts\codex_selfcheck.py --md       # ตารางสำหรับวางในรายงาน
```

4. **ตรวจด้วยมือตามส่วน ข** กับทุกข้อที่ตัวตรวจระบุว่า "ต้องทำเองโดยปิดเฉลย" และทุกบทเรียนที่แก้
5. แก้สิ่งที่เจอ แล้วกลับไปข้อ 1
6. เขียนรายงาน ปิดท้ายด้วยหัวข้อ "ผลตรวจตัวเอง" ตามแบบในข้อ ค
7. บอกว่าเสร็จ

ถ้าเทียบกับ commit อื่นที่ไม่ใช่ล่าสุด ใช้ `--base <รหัส commit>` (เช่น เมื่อ Claude push งานอื่นระหว่างที่คุณทำ)

## ข. สิ่งที่ต้องตรวจด้วยมือ

วิธีคิดหลัก: **เปลี่ยนบทบาทเป็นผู้ตรวจที่พยายามหักล้างงานตัวเอง** ใช้ไฟล์ JSON ที่ build แล้ว ไม่ใช่ต้นฉบับที่เพิ่งเขียน

| # | เกณฑ์ | วิธีตรวจ | ข้อผิดจริงที่เป็นที่มา |

## กติกาของรายงาน

- **ช่อง "พบและแก้เอง" ที่ว่างทุกแถวไม่ใช่ผลที่ดี** ถ้าตรวจจริงมักเจออย่างน้อยหนึ่งจุด รอบ 11 คุณเจอ 4 จุด รอบ 14 เจอ 5 จุด
- **ยกข้อความจริง** ตารางที่ทุกแถวเขียนว่า "จำกัดเงื่อนไขและข้อยกเว้น" (รอบ 13) ตรวจตามไม่ได้ ต้องเห็นว่ากฎเดิมคืออะไรและแก้เป็นอะไร
- ตัวเลขทุกตัวมาจากตัวตรวจหรือ `git diff` ไม่ใช่ประมาณ
- เกณฑ์ใดไม่เกี่ยวกับงานรอบนั้น เขียนว่า "ไม่เกี่ยว" พร้อมเหตุผลสั้น ๆ อย่าเว้นว่าง
- ถ้าทำไม่ครบขอบเขต บอกว่าทำถึงไหน **อย่าเขียนว่าเสร็จ**
- ถ้าไม่เห็นด้วยกับเกณฑ์หรือกับข้อเสนอของ Claude เขียนเหตุผลได้ ผู้เป็นเจ้าของไฟล์เป็นผู้ตัดสิน
