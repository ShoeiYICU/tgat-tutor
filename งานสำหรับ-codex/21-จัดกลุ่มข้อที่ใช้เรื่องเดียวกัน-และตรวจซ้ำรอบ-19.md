## ส่วนที่ 1 — ไฟล์จัดกลุ่มสำหรับชุดสอบเสมือน

รอบ 19 คุณพบ 10 กลุ่มที่ข้อใช้บทอ่านหรือสถานการณ์เดียวกันแต่หลุดการกันของตัวสุ่มชุดสอบ และเสนอให้ผู้แต่งกำหนด key เอง
Claude รับข้อเสนอ แต่จะไม่เพิ่มฟิลด์ลงในโจทย์ทีละข้อ (ต้องแก้สคีมาและตัวตรวจ) ขอเป็น **ไฟล์จัดกลุ่มไฟล์เดียว** แทน แล้ว Claude จะต่อเข้ากับตัวสุ่ม

### สิ่งที่ต้องส่ง: `งานสำหรับ-codex/กลุ่มข้อที่ใช้เรื่องเดียวกัน.json`

```json
{
  "version": 1,
  "groups": [
    {
      "id": "tgat2.tea_shop",
      "kind": "passage",
      "note": "บทอ่านร้านชานมติดป้ายปริมาณน้ำตาล",
      "ids": ["prob.tgat2.language.reading.main_idea.0002", "prob.tgat2.language.reading.inference.0001"],
      "leaks": "ข้อเรียงประโยคได้ลำดับจากบทอ่านเต็มของข้ออื่น"
    }
  ]
}
```

| ช่อง | ความหมาย |
|---|---|
| `id` | ชื่อกลุ่ม ขึ้นต้นด้วยรหัสวิชา ใช้ตัวพิมพ์เล็กและขีดล่าง |
| `kind` | `passage` (บทอ่านเดียวกัน) หรือ `scenario` (เงื่อนไขหรือสถานการณ์ชุดเดียวกัน) |
| `ids` | id ของทุกข้อในกลุ่ม ต้องมีอย่างน้อย 2 ข้อ |
| `leaks` | อธิบายสั้น ๆ ว่าออกพร้อมกันแล้วเสียอะไร: บอกคำตอบกัน · ได้เปรียบจากการอ่านซ้ำ · หรือ "ไม่รั่ว แต่ซ้ำเรื่อง" |

### ขอบเขตและกติกา

- ครอบคลุม **ทั้งสี่วิชา** ไม่ใช่เฉพาะ 10 กลุ่มที่พบแล้ว ไล่หาด้วยสคริปต์ก่อน (ข้อความร่วมยาว ๆ ระหว่างข้อ ชื่อเฉพาะที่ซ้ำ ตัวเลขชุดเดียวกัน) แล้วอ่านยืนยันด้วยตา
- ข้อหนึ่งอยู่ได้กลุ่มเดียว ถ้าข้อหนึ่งเกี่ยวกับสองเรื่อง ให้รวมเป็นกลุ่มเดียวและอธิบายใน `note`
- ข้อที่ใช้ **แม่แบบเดียวกันแต่ตัวเลขต่างกัน** ไม่นับเป็นกลุ่ม (เช่น อนุกรมสองข้อจากแม่แบบเดียวกัน) กลุ่มหมายถึงเรื่องหรือข้อมูลชุดเดียวกันจริง
- ตรวจไฟล์ด้วยสคริปต์ก่อนส่ง: เป็น JSON ที่อ่านได้ · ทุก id มีอยู่จริงใน `data/problems/` · ไม่มี id ซ้ำข้ามกลุ่ม

### ตัวเลขที่ต้องรายงาน

หลังจัดกลุ่ม ถ้าตัวสุ่มเลือกได้กลุ่มละหนึ่งข้อ แต่ละส่วนของผังสอบเหลือข้อให้เลือกกี่ข้อเทียบกับที่ชุดเต็มต้องใช้ (ตารางเดียวกับรายงานรอบ 19 ข้อ 2.1)
ถ้าส่วนใดเหลือน้อยกว่าสองเท่าของที่ต้องใช้ ให้ระบุ เพราะผู้ที่สอบซ้ำจะเจอเรื่องเดิมเกือบทุกครั้ง

## ส่วนที่ 2 — ตรวจซ้ำงานแก้รอบ 19 ของ Claude

Claude เขียนคำอธิบายเฉลยของโจทย์ 36 ข้อใหม่ทั้งหมด และแก้ตัวสร้างสองตัว ดูด้วย `git log -3` และ `git diff HEAD~1 -- scripts/providers/shape2d_items.py data/problems/tgat2.spatial.*`

| สิ่งที่แก้ | ตรวจอะไร |
|---|---|
| `by_rotation` · `by_reflection` 24 ข้อ: `solution_steps` · `hints` · `answer_explanation_md` เขียนใหม่ตาม `mode` ของแต่ละข้อ | ข้อ `altered` ไม่มีข้อความเรื่องภาพสะท้อน · ข้อ `reflection` บอกว่า "กลับด้านแล้วหมุนจึงทับ" ซึ่ง **ต้องเป็นจริงกับรูปของข้อนั้น** ลองทำตามกับรูปจริงอย่างน้อย 6 ข้อ |
| ข้อ `altered` บอกว่า "หมุนครบสี่ท่าแล้วยังมีช่องที่ไม่ตรงกับรูปอื่น" | มีข้อใดไหมที่รูปที่ย้ายช่องแล้ว **บังเอิญเป็นภาพสะท้อน** ของอีกสี่รูป ถ้ามี คำอธิบายยังถูก แต่ `why_odd` ("มีช่องหนึ่งย้ายตำแหน่ง") จะไม่ใช่คำอธิบายที่ดีที่สุด |
| `symmetry_reflection` 12 ข้อ: ใช้วิธีหมุนครบสี่ท่าเทียบทีละช่อง | คำตอบของแต่ละข้อตรงกับผลของวิธีนี้ทุกข้อ (ภาพหมุน หรือ ภาพสะท้อน) และเหตุผลของตัวลวงยังสอดคล้องกับคำอธิบายใหม่ |
| ตัวสร้าง `_OddOneOut` และ `_RotOrRef` | อ่านโค้ดว่าข้อความทุกสาขาเป็นประโยคที่ถูก ไม่มีสาขาใดอ้างจุดสังเกตของรูป |
| บทเรียน `by_rotation` · `by_reflection` · `symmetry_reflection` | บทเรียนยังสอนทิศการเลี้ยวเป็นเทคนิคคัดกรอง ส่วนเฉลยของโจทย์ใช้วิธีหมุนสี่ท่า **สองอย่างนี้ขัดกันในสายตาผู้เรียนไหม** ถ้าขัด เสนอประโยคเชื่อมที่ควรเพิ่มในบทเรียน |
