# วิธีสั่งงาน Codex (คัดลอกไปวางได้เลย)

## ก่อนเริ่ม

1. เปิด Codex ในโฟลเดอร์ `D:\project\addmission`
2. สั่งทีละใบงาน อย่าสั่งพร้อมกันหลายใบ เพราะจะแก้ไฟล์ชนกันเอง
3. ระหว่าง Codex ทำงานอยู่ ให้บอก Claude ว่ากำลังให้ Codex ทำใบไหน Claude จะได้ไม่แตะไฟล์เดียวกัน

## ข้อความสำหรับวาง (ใบสั่งงานที่ 1 · ตรวจ TGAT1)

```
โปรเจกต์นี้คือเว็บติวสอบ TGAT ภาษาไทย ผมกำลังแบ่งงานกับผู้ช่วยอีกตัวหนึ่ง

งานของคุณรอบนี้: อ่านไฟล์ งานสำหรับ-codex/00-อ่านก่อนเริ่ม.md ให้จบก่อน
แล้วทำตามใบสั่งงาน งานสำหรับ-codex/01-ตรวจเนื้อหา-TGAT1.md

ข้อสำคัญ
- แก้ได้เฉพาะไฟล์ใน content/tgat1/ และไฟล์รายงานในโฟลเดอร์ งานสำหรับ-codex/ เท่านั้น
- ห้ามแตะ web/, scripts/, content/tgat2/, content/tgat3/, data/ (ไฟล์ใน data สร้างอัตโนมัติ)
- ห้ามรัน scripts/build_site.py
- ทุกครั้งที่แก้เสร็จ ให้รัน (PowerShell)
    $env:PYTHONIOENCODING="utf-8"; python scripts\build_content.py tgat1; python scripts\validate.py; python scripts\render_template.py --stress
  ต้องได้ "ต้องแก้: 0" และ stress "ผ่านทั้งหมด"
- จบงานให้เขียนรายงานตามรูปแบบในใบสั่งงาน

เริ่มจากไฟล์ content/tgat1/speaking_qr.py ก่อน แล้วรายงานให้ผมดูก่อนไปไฟล์ถัดไป
```

## ข้อความสำหรับวาง (ใบสั่งงานที่ 3 · เพิ่มโจทย์)

```
อ่าน งานสำหรับ-codex/00-อ่านก่อนเริ่ม.md แล้วทำตาม งานสำหรับ-codex/03-เพิ่มโจทย์-TGAT1-TGAT3.md

เพิ่มโจทย์หัวข้อละ 2 ข้อ (ข้อยาก 1 + ข้อกลาง 1) ในไฟล์ content/tgat1/ และ content/tgat3/

ทำทีละไฟล์ และหลังจบแต่ละไฟล์ให้รัน
$env:PYTHONIOENCODING="utf-8"; python scripts\build_content.py tgat1; python scripts\validate.py; python scripts\render_template.py --stress

เงื่อนไขที่พลาดบ่อย: คำใบ้ห้ามมีคำตอบอยู่ในนั้น · ตัวลวงทุกตัวต้องมีเหตุผล · วิธีคิดอย่างน้อย 2 ขั้น
· คำตอบไม่ควรเป็นตัวเลือกที่ยาวที่สุดหรือสั้นที่สุด
```

## เมื่อ Codex ทำงานเสร็จ ให้บอก Claude ว่า

```
Codex ทำใบสั่งงานที่ N เสร็จแล้ว ช่วยตรวจผลงานและ build ขึ้นเว็บให้ด้วย
```

Claude จะ

1. รัน validate + stress ซ้ำเพื่อยืนยัน
2. สุ่มอ่านของที่ Codex แก้ ว่าตรงกับกฎของโปรเจกต์ไหม
3. รัน `build_site.py` เพื่อเอาขึ้นเว็บ (Claude เป็นคนเดียวที่รันคำสั่งนี้)
4. อัปเดต `บันทึกงาน.md` ให้ตรงกับของจริง

## ถ้า Codex เจอทางตัน

บอก Codex ว่า **"ข้ามข้อนั้นไปก่อน แล้วบันทึกไว้ในหัวข้อ 'สิ่งที่พบแต่ยังไม่ได้แก้' ในรายงาน"**
ดีกว่าปล่อยให้แก้ข้ามขอบเขตจนชนกับงานของอีกฝั่ง
