## 1. โปรเจกต์นี้คืออะไร

เว็บติวสอบ TGAT ภาษาไทย (static site) สำหรับนักเรียนที่เริ่มจากศูนย์ เจ้าของโปรเจกต์จะใช้ยื่นพอร์ตโฟลิโอ TCAS
กำหนดส่ง **15 ตุลาคม 2569**

- โค้ดอยู่ที่ `D:\project\addmission`
- เนื้อหาทั้งหมด **เขียนเป็นโค้ด Python** ใน `content/**/*.py` แล้ว "build" ออกมาเป็น JSON ใน `data/`
- เว็บอ่านไฟล์ที่ build จาก `data/` อีกทีผ่าน `scripts/build_site.py` ไปเป็น `web/data/`
- ปัจจุบัน: บทเรียน 140 หัวข้อ · โจทย์ 903 ข้อ · ผ่านตัวตรวจทุกตัว

## 2. กฎที่ห้ามละเมิดเด็ดขาด

1. **ห้ามแต่งหรือนึกข้อสอบจริงจากความจำ** ทุกข้อในเว็บนี้ต้องเป็นโจทย์ที่แต่งขึ้นใหม่เท่านั้น
   ห้ามคัดลอกข้อสอบจริง ห้ามเขียนว่า "ข้อสอบปีนี้ออกแบบนี้"
2. **ห้ามยืนยันโครงสอบ สัดส่วนคะแนน หรือคะแนนขั้นต่ำเอง** ถ้าต้องอ้าง ให้อ้างจาก `spec/02-exam-map.md` เท่านั้น
3. **ห้ามเปิด แก้ หรือคัดลอกอะไรจาก** `data/exams/`, `all_data/`, `data/_generate/` (เป็นไฟล์ข้อสอบจริงที่ห้ามเผยแพร่)
4. **ห้ามแก้ `topic_id`** เปลี่ยนได้แค่ชื่อไทย (`name_th`)
5. เนื้อหาที่ AI เขียนยังถือเป็นฉบับร่าง (`review_status: "ai_draft"`) ห้ามเปลี่ยนสถานะนี้เอง

## 5. โครงสร้างของไฟล์เนื้อหา

ไฟล์ใน `content/` ใช้ helper จาก `scripts/author.py` ดูตัวอย่างจริงได้ในไฟล์ที่จะแก้ รูปแบบคร่าว ๆ:

```python
from author import *

tid = "tgat1.reading.comprehension.main_idea"
L = lesson(tid, "ชื่อบทเรียน", "สรุปหนึ่งบรรทัด",
    objectives=[...], minutes=20, prereq=[...], nxt=[...],
    blocks=[hook(...), concept(...), technique(...), example(...), pitfall(...), summary(...), check(...)],
    patterns=[...], sources=[...])

P = [
    q("โจทย์", "คำตอบที่ถูก",
      [("ตัวลวง 1", "เหตุผลที่ผิด"), ("ตัวลวง 2", "เหตุผลที่ผิด"), ...],   # TGAT1 มี 3 ตัวลวง (4 ตัวเลือก)
      [("ขั้นที่ 1", "ทำไมถึงทำแบบนั้น"), ("ขั้นที่ 2", "...")],            # อย่างน้อย 2 ขั้น
      ["คำใบ้ 1", "คำใบ้ 2", "คำใบ้ 3"],                                  # 3 ข้อพอดี
      "เฉลยอธิบาย", diff=2, sec=35, tags=["misconception_tag"]),
]
save(tid, "TGAT1", "mcq4", P, lesson=L)
```

TGAT3 ใช้ `t(stem, [(ข้อความ, คะแนน, เหตุผล), ...], steps, hints, explain, diff=)` โดยคะแนนคือ 1 / 0.75 / 0.5 / 0.25
และต้องมีตัวเลือกที่ได้ 1.00 เพียงตัวเดียว

## 6. เกณฑ์คุณภาพที่ตัวตรวจบังคับอยู่แล้ว

- คำใบ้ 3 ข้อพอดี · วิธีคิดอย่างน้อย 2 ขั้น · ตัวลวงทุกตัวต้องมีเหตุผล
- **คำใบ้ห้ามมีคำตอบอยู่ในนั้น**
- ตัวเลือกห้ามซ้ำกัน · โจทย์ห้ามซ้ำกับข้ออื่นในหัวข้อเดียวกัน
- **คำตอบต้องไม่ใช่ตัวเลือกที่ยาวที่สุดหรือสั้นที่สุดเกินครึ่งของไฟล์** (ผู้สอบจะเดาได้จากความยาว)
- TGAT3 ต้องมีอย่างน้อย 3 ระดับคะแนนในหนึ่งข้อ

ถ้าตัวตรวจเตือนเรื่องไหน ให้แก้เนื้อหาให้ผ่าน ไม่ใช่แก้ตัวตรวจ

## 7. สไตล์ภาษาไทยของโปรเจกต์

- เขียนให้คนที่เริ่มจากศูนย์อ่านรู้เรื่อง ประโยคสั้น ไม่ใช้ศัพท์เทคนิคโดยไม่อธิบาย
- ไม่ใช้อีโมจิ ไม่ใช้เครื่องหมายอัศเจรีย์รัว ๆ
- ใช้ "คุณ" เรียกผู้อ่าน
- เว้นวรรคแบบไทย (ไม่ใส่จุลภาคพร่ำเพรื่อ) และเว้นวรรคก่อน-หลังคำภาษาอังกฤษ
