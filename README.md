# ติว TGAT — เว็บเรียนและฝึกโจทย์ TGAT/TPAT ที่สร้างเนื้อหาด้วยโค้ด

เว็บนิ่ง (static) สำหรับเตรียมสอบ TCAS ภาษาไทย ใช้ฟรี ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล
ทำขึ้นเพื่อใช้ยื่นแฟ้มสะสมผลงาน และให้นักเรียนคนอื่นใช้ได้จริง

| | |
|---|---|
| **บทเรียน** | 164 หัวข้อ |
| **โจทย์** | 1,201 ข้อ (แต่งขึ้นใหม่ทั้งหมด ไม่ใช่ข้อสอบจริง) |
| **วิชา** | TGAT1 · TGAT2 · TGAT3 ครบทุกหัวข้อ · TPAT3 ทำแล้ว 24 จาก 26 หัวข้อ |
| **รูปที่วาดด้วยโค้ด** | 765 รูป |

> 📄 รายละเอียดทั้งหมดอยู่ใน [สรุปโปรเจกต์.md](สรุปโปรเจกต์.md)

## แนวคิดหลัก: เนื้อหาเป็นโค้ด ไม่ใช่เอกสาร

```
content/**.py  →  data/lessons/*.json   →  web/data/**  →  เบราว์เซอร์
                  data/problems/*.json
                        ↑
              validate.py + stress test
              ถ้าไม่ผ่าน ไฟล์จะไม่ถูกสร้าง
```

บทเรียนและโจทย์ทุกข้อเขียนเป็นโปรแกรม Python แล้วให้เครื่องแปลงเป็นไฟล์ข้อมูลของเว็บ
ข้อดีคือกฎคุณภาพถูกบังคับด้วยเครื่อง เช่น คำใบ้ต้องมี 3 ข้อ · ตัวลวงทุกตัวต้องมีเหตุผล ·
คำใบ้ห้ามมีคำตอบอยู่ในนั้น · คำตอบต้องไม่ใช่ตัวเลือกที่ยาวหรือสั้นที่สุดเกินครึ่งของไฟล์

## โจทย์ที่โปรแกรมคิดคำตอบเอง

| กลุ่ม | โปรแกรมทำอะไร |
|---|---|
| พับกล่อง | พับแผ่นคลี่จริงในสามมิติ รู้ว่าหน้าไหนตรงข้ามกัน และลูกศรบนหน้าหนึ่งชี้ไปทางไหนหลังพับ |
| หมุนภาพสามมิติ | เก็บทรงเป็นพิกัดลูกบาศก์ หมุนด้วยการแปลงพิกัด แล้ววาดภาพจากพิกัดนั้น |
| คาน รอก เฟือง | จำลองระบบเป็นข้อมูล แล้วให้ทั้งภาพและเฉลยสร้างจากข้อมูลชุดเดียวกัน ภาพกับคำตอบจึงตรงกันเสมอ |
| ปริศนาเงื่อนไข | ไล่ทุกความเป็นไปได้ เพื่อยืนยันว่าคำตอบมีแบบเดียวจริง |
| ประกอบชิ้นส่วน | ไล่วางชิ้นส่วนทุกตำแหน่งและทุกมุมหมุน เพื่อพิสูจน์ว่าตัวลวงประกอบไม่ได้ |
| โจทย์ตัวเลขแบบแม่แบบ | สุ่มค่าใหม่ได้ และถูกสุ่มทดสอบข้อละ 200 ครั้งก่อนขึ้นเว็บ |

## ฟีเจอร์ของเว็บ

บทเรียนรายหัวข้อ · ฝึกโจทย์พร้อมคำใบ้ 3 ระดับและเฉลยทีละขั้น · สุ่มโจทย์ใหม่ได้ไม่จำกัด ·
สอบเสมือนจับเวลาตามสัดส่วนผังสอบจริง · หน้าความคืบหน้าพร้อมกราฟ · ฝึกเฉพาะข้อที่เคยผิด ·
รวมลิงก์ข้อสอบตัวอย่างทางการ · โหมดสว่างและมืด

ความคืบหน้าของผู้ใช้เก็บในเบราว์เซอร์ของผู้ใช้เอง ไม่มีการส่งข้อมูลออกและไม่มีระบบสมาชิก

## โครงสร้างโฟลเดอร์

```
content/    เนื้อหาเขียนเป็นโค้ด Python
scripts/    เครื่องมือ build ตรวจคุณภาพ วาดรูป พับกล่อง ทรงสามมิติ
data/       ไฟล์ที่ build ออกมา (ห้ามแก้ด้วยมือ)
web/        ★ ตัวเว็บที่ deploy จริง
spec/       สเปคของโครงการและผังสอบที่ยืนยันแล้ว
```

## คำสั่งที่ใช้

```bash
python scripts/build_content.py            # เนื้อหา → data/
python scripts/validate.py                 # ต้องได้ "ต้องแก้: 0"
python scripts/render_template.py --stress # สุ่มทดสอบแม่แบบข้อละ 200 ครั้ง
python scripts/build_site.py               # data/ → web/data/
python -m http.server 8765 --directory web # ดูเว็บที่ localhost:8765
```

## หมายเหตุสำคัญ

- เกณฑ์คะแนนย่อยของ TGAT3 ในเว็บนี้เป็นเกณฑ์ที่กำหนดขึ้นเพื่อฝึก ไม่ใช่เกณฑ์ทางการ
