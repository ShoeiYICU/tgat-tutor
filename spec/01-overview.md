# 01 — ภาพรวมระบบ และกฎการตั้งรหัส

> ไฟล์นี้แนบให้ AI เป็น context เพื่อให้มันเข้าใจว่าของที่มันผลิตจะไปอยู่ที่ไหน

---

## 1. โครงข้อมูล 3 ชั้น

```
EXAM (สนามสอบ)            เช่น A-Level 61 คณิตศาสตร์ประยุกต์ 1
  └─ TOPIC TREE (ผังหัวข้อ)   ← กระดูกสันหลัง ใช้ร่วมกันทั้ง 2 ฟีเจอร์
       ├─ LESSON (บทเรียน)     ← ฟีเจอร์ A: Learn   (1 หัวข้อย่อย = 1 บทเรียน)
       └─ PROBLEM (โจทย์)      ← ฟีเจอร์ B: Practice (1 หัวข้อย่อย = หลายข้อ)
```

**สำคัญ:** `TOPIC TREE` ต้องเสร็จก่อน จึงจะเขียน `LESSON` หรือ `PROBLEM` ได้
เพราะทั้งสองอย่างต้องอ้าง `topic_id` ที่มีอยู่จริงในผัง ห้ามคิด `topic_id` ขึ้นมาเองตอนเขียนบทเรียน

---

## 2. ผังหัวข้อ (Topic Tree) มี 3 ระดับ

| ระดับ | เรียกว่า | ตัวอย่าง | มีบทเรียน/โจทย์ไหม |
|---|---|---|---|
| 1 | `subject` (วิชา) | `math` | ไม่มี |
| 2 | `branch` (สาระ/บท) | `math.trig` (ตรีโกณมิติ) | ไม่มี |
| 3 | `leaf` (หัวข้อย่อย) | `math.trig.sine_law` (กฎของไซน์) | **มี** |

- อนุญาตให้มี `branch` ซ้อนได้ไม่เกิน 2 ชั้น เช่น `math.trig.identity.sum_diff`
- **ขนาดที่เหมาะสมของ 1 `leaf`** = สอนได้จบใน **10–30 นาที** และออกข้อสอบได้ 5–20 ข้อ
  - ถ้าอธิบายเกิน 30 นาที → ใหญ่เกินไป ให้ซอย
  - ถ้าออกโจทย์ได้ไม่ถึง 5 ข้อ → เล็กเกินไป ให้รวมกับหัวข้อข้างเคียง

## 3. กฎการตั้งรหัส (ID Convention) — ห้ามผิด

### 3.1 `topic_id`
รูปแบบ: `<subject>.<branch>[.<subbranch>].<leaf>`

- ใช้ **ตัวพิมพ์เล็ก a–z, ตัวเลข 0–9 และ `_`** เท่านั้น คั่นชั้นด้วย `.`
- เป็น **ภาษาอังกฤษ** (ชื่อไทยไปอยู่ในฟิลด์ `name_th`)
- ห้ามมีช่องว่าง ห้ามมีอักษรไทย ห้ามใช้ `-`
- **ห้ามเปลี่ยนรหัสหลังสร้างแล้ว** (ถ้าต้องเปลี่ยนชื่อ ให้แก้ `name_th` อย่างเดียว)

ตัวอย่างที่ถูก:
```
math.trig.sine_law
phys.mechanics.newton_second_law
chem.stoich.limiting_reagent
bio.genetics.mendel_law
thai.grammar.word_class
eng.reading.main_idea
soc.history.ayutthaya
tgat2.numerical.percentage
```

ตัวอย่างที่ผิด:
```
Math.Trig.SineLaw        ← มีตัวพิมพ์ใหญ่
math.ตรีโกณ.sine         ← มีอักษรไทย
math.trig.sine-law       ← ใช้ขีดกลาง
sine_law                 ← ไม่มีชั้นวิชา
```

### 3.2 `subject` (ชั้นบนสุด) — ใช้ค่าจากรายการนี้เท่านั้น

| รหัส | วิชา |
|---|---|
| `math` | คณิตศาสตร์ |
| `phys` | ฟิสิกส์ |
| `chem` | เคมี |
| `bio` | ชีววิทยา |
| `sci` | วิทยาศาสตร์ทั่วไป/ประยุกต์ (โลก ดาราศาสตร์ ฯลฯ) |
| `thai` | ภาษาไทย |
| `eng` | ภาษาอังกฤษ |
| `soc` | สังคมศึกษา |
| `tgat1` `tgat2` `tgat3` | TGAT แต่ละพาร์ท |
| `tpat1` … `tpat5` | TPAT แต่ละวิชา |
| `lang_fr` `lang_de` `lang_jp` `lang_kr` `lang_cn` `lang_pali` `lang_es` | ภาษาต่างประเทศอื่น |

### 3.3 `problem_id`
รูปแบบ: `prob.<topic_id ที่ตัด subject ออกไม่ได้ ใช้เต็ม>.<เลข 4 หลัก>`
เช่น `prob.math.trig.sine_law.0001`

### 3.4 `exam_code`
เช่น `ALEVEL_61`, `ALEVEL_64`, `TGAT2`, `TPAT3` (ดูรายการเต็มใน `02-exam-map.md`)

## 4. กฎการเขียนเนื้อหา (ใช้กับทั้ง lesson และ problem)

### 4.1 ภาษา
- เนื้อหาเป็น **ภาษาไทย** (ยกเว้นวิชาภาษาต่างประเทศ)
- ใช้ศัพท์วิชาการตามที่ สสวท./กระทรวงศึกษาฯ ใช้ และใส่คำอังกฤษในวงเล็บครั้งแรกที่พบ
  เช่น "ดิสคริมิแนนต์ (discriminant)"
- น้ำเสียง: พูดกับเด็ก ม.ปลายที่เริ่มจาก 0 — ตรงไปตรงมา ไม่กันเอง ไม่ใช้คำว่า "ง่ายมาก" หรือ "แค่นี้เอง"

### 4.2 สูตรคณิตศาสตร์
- ใช้ **LaTeX ในรูปแบบที่ KaTeX รองรับ**
- แบบแทรกในบรรทัด: `$...$`  แบบขึ้นบรรทัดใหม่: `$$...$$`
- ห้ามใช้ `\begin{align}` (KaTeX พื้นฐานไม่รองรับ) ให้ใช้ `\begin{aligned}` ข้างใน `$$...$$`
- ในไฟล์ JSON ต้อง **escape backslash เป็น 2 ตัว** เช่น `"$$x=\\frac{1}{2}$$"`

### 4.3 รูปภาพ / กราฟ / แผนภาพ
AI วาดรูปไม่ได้ ห้ามใส่ลิงก์รูปลอย ๆ ให้ใช้ฟิลด์ `figures` โดยเลือก 1 ใน 2 แบบ:
- `"type": "svg"` → ใส่โค้ด SVG มาเลย (เหมาะกับกราฟ/แผนภาพเรขาคณิตง่าย ๆ ให้วาดด้วย SVG ตรง ๆ)
- `"type": "needs_drawing"` → เขียน `description` บรรยายว่าต้องวาดอะไร ให้คนมาวาดทีหลัง
ทุกกรณีต้องมี `alt` (คำบรรยายสำหรับคนตาบอด/กรณีรูปไม่ขึ้น)

### 4.4 หน่วยและตัวเลข
- ใส่หน่วยเสมอ และใช้หน่วย SI เว้นแต่โจทย์ระบุอื่น
- ทศนิยมใช้จุด ไม่ใช้ลูกคิดคั่นหลักพันในสูตร (ในเนื้อความใส่ได้)

## 5. สิ่งที่ทำให้เว็บนี้ต่างจากที่อื่น (AI ต้องรู้เพื่อใส่ข้อมูลให้ครบ)

ระบบจะเอาข้อมูลไปใช้ 3 อย่างที่ต้องพึ่งฟิลด์พิเศษ **ถ้าขาดฟิลด์เหล่านี้ ฟีเจอร์จะทำไม่ได้เลย**

| ฟีเจอร์ | ฟิลด์ที่จำเป็น | เหตุผล |
|---|---|---|
| สร้างโจทย์ใหม่ที่ยากเท่าเดิมไม่จำกัดข้อ | `template` (ตัวแปร + สูตรคำนวณเฉลย) | ระบบสุ่มตัวเลขแล้วคำนวณเฉลยด้วยโค้ด ไม่ให้ AI เดาเฉลย |
| วิเคราะห์ว่าผู้ใช้พลาดเพราะอะไร | `distractor_reasons` + `misconception_tags` | รู้ว่าเลือกตัวเลือกไหน = เข้าใจผิดเรื่องอะไร |
| บอกว่า "ต้องกลับไปซ่อมพื้นฐานตัวไหนก่อน" | `requires` ใน topic | ไต่ผังย้อนไปหาต้นตอความไม่เข้าใจ |

## 6. คำที่ใช้ในเอกสารชุดนี้

| คำ | ความหมาย |
|---|---|
| หัวข้อย่อย / leaf | หน่วยเล็กสุดที่มีบทเรียนและโจทย์ |
| โจทย์แม่แบบ / template | โจทย์ที่เขียนเป็นสูตรมีตัวแปร สุ่มค่าได้ไม่จำกัด |
| ตัวเลือกลวง / distractor | ตัวเลือกผิดใน MCQ ที่ออกแบบจากความเข้าใจผิดจริง |
| แนวข้อสอบ | โจทย์ที่แต่งขึ้นใหม่ให้เหมือนข้อสอบจริง **ไม่ใช่ข้อสอบจริง** |
