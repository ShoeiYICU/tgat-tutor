# 05 — Prompt สำเร็จรูป: เขียนบทเรียน (ฟีเจอร์ A — เรียนจาก 0)

## วิธีใช้
1. แนบ `03-schema.md` + ไฟล์ผังหัวข้อของวิชานั้น (`data/topics/<subject>.topics.json`)
2. คัดลอกกรอบด้านล่าง แก้ช่อง `<< >>` แล้วสั่ง **ทีละ 1 หัวข้อย่อย**
3. บันทึกเป็น `data/lessons/<topic_id>.json`

> **ห้ามสั่งทีเดียวหลายหัวข้อ** ต่อให้ AI ทำได้ ผลลัพธ์จะตื้นและอธิบายข้าม
> หัวข้อละ 1 คำสั่ง คือจุดที่คุณภาพกับความเร็วสมดุลที่สุด

## PROMPT — คัดลอกทั้งกรอบนี้

```
คุณเป็นครูสอนวิชา <<คณิตศาสตร์>> ระดับมัธยมปลายของไทย ที่เก่งเรื่องอธิบายให้คนที่ไม่มีพื้นฐานเข้าใจ

## ผู้อ่านบทเรียนนี้คือใคร (สำคัญที่สุด อ่านให้ดี)
- เด็กไทย ม.ปลาย ที่ "ไม่เคยเรียนเรื่องนี้เลย" หรือเรียนแล้วไม่เข้าใจ
- **ไม่มีเงินเรียนคอร์สติว** และไม่มีครูให้ถาม
- เขามีแค่บทเรียนนี้ ดังนั้นบทเรียนต้องสมบูรณ์ในตัวเอง
  ห้ามเขียนว่า "ดูเพิ่มเติมในหนังสือ" หรือ "ถามครูของคุณ"
- ถ้าเขาอ่านจบแล้วยังทำโจทย์พื้นฐานไม่ได้ ถือว่าบทเรียนนี้ล้มเหลว

## หัวข้อที่ต้องเขียน
- topic_id: <<math.trig.sine_law>>
- ชื่อหัวข้อ: <<กฎของไซน์>>
- ระดับชั้น: <<ม.5>>
- ต้องรู้มาก่อน (requires): <<math.trig.ratio, math.geometry.triangle_basic>>
- ออกสอบใน: <<A-Level 61 คณิตศาสตร์ประยุกต์ 1>>

## วิธีเขียนที่ต้องทำ
1. **อธิบายที่มาก่อนให้สูตร** อย่าโยนสูตรใส่หน้าผู้อ่าน ต้องให้เขารู้ว่าสูตรมาจากไหน
2. ใช้ภาษาไทยที่ตรงไปตรงมา ประโยคสั้น
   - ห้ามใช้คำว่า "ง่ายมาก" "แค่นี้เอง" "ชัดเจนว่า" เพราะคนที่ไม่เข้าใจจะรู้สึกแย่
   - ห้ามข้ามขั้นตอนโดยพูดว่า "จะเห็นได้ว่า"
3. ทุกขั้นในตัวอย่างต้องมี why_md บอก **เหตุผลที่ทำขั้นนั้น** ไม่ใช่แค่บอกว่าทำอะไร
4. ใส่ศัพท์อังกฤษในวงเล็บครั้งแรกที่พบคำศัพท์วิชาการ
5. บล็อก pitfall ต้องมาจากความเข้าใจผิดที่เกิดขึ้นจริงกับนักเรียน ไม่ใช่กับดักที่คิดขึ้นลอย ๆ
6. ตัวอย่างต้องไล่จากง่ายไปยาก (difficulty 1-2 -> 3 -> 4)
7. ถ้าเรื่องนี้ต้องมีรูปจึงจะเข้าใจ ให้ใส่ figures โดยเลือก type เป็น "svg" ถ้าวาดด้วย SVG ง่าย ๆ ได้
   หรือ "needs_drawing" พร้อม description ถ้าวาดยาก ห้ามละรูปไปเฉย ๆ
```

## Prompt เสริม 1 — ตรวจความถูกต้องทางวิชาการ (ทำทุกบทเรียน)

ใช้ AI **อีกตัว** ตรวจ (GPT เขียน -> Claude ตรวจ หรือกลับกัน) จะจับผิดได้ดีกว่าให้ตัวเดิมตรวจงานตัวเอง

```
นี่คือบทเรียนวิชา <<คณิตศาสตร์>> เรื่อง <<กฎของไซน์>> ที่ร่างด้วย AI
โปรดตรวจแบบผู้ตรวจตำราเรียน รายงานเป็นรายการ ไม่ต้องเขียน JSON ใหม่

ตรวจ 7 ข้อ
1. เนื้อหาผิดทางวิชาการ (ผิดข้อเท็จจริง ผิดสูตร ผิดเงื่อนไขการใช้)
2. การคำนวณในตัวอย่างผิด — ให้คำนวณซ้ำทุกข้อและบอกคำตอบที่ถูก
3. ขั้นตอนที่กระโดด — จุดที่คนไม่มีพื้นฐานจะตามไม่ทัน
4. สูตรที่ใช้แต่ไม่ได้อธิบายที่มา หรือไม่ได้บอกเงื่อนไขการใช้
5. ศัพท์ที่ไม่ตรงกับที่ใช้ในหลักสูตรไทย
6. pitfall ที่ไม่ใช่ความเข้าใจผิดจริง (เป็นกับดักที่คิดขึ้นเอง)
7. objectives ที่บทเรียนไม่ได้สอนจริง

ตอบเป็นตาราง: [ข้อที่เท่าไร] [ตำแหน่ง block ที่พบ] [ปัญหา] [ควรแก้เป็น] [ความรุนแรง: ต้องแก้/ควรแก้/เสนอ]

<<วาง JSON บทเรียนที่นี่>>
```

## Prompt เสริม 2 — สำหรับวิชาที่ไม่ใช่การคำนวณ

วิชาไทย สังคม อังกฤษ TGAT3 ต้องปรับ prompt หลักดังนี้:

| แทนที่ | ด้วย |
|---|---|
| บล็อก `formula` | ใช้ `formula` เก็บ **หลักการ/กฎ/โครงสร้าง** แทนสูตร เช่น "โครงสร้าง passive voice" `formula_tex` เว้น `""` แล้วใส่รูปแบบใน `name` และ `use_when` |
| `example` แบบคำนวณ | ใช้เป็น **ตัวอย่างการวิเคราะห์** เช่น ยกบทประพันธ์มาแล้วชี้ทีละบรรทัดว่ารู้ได้อย่างไรว่าใช้โคลงชนิดนี้ |
| ตัวอย่าง 3 ข้อ | เพิ่มเป็น 4–5 ข้อ เพราะวิชาแบบนี้เรียนจากการเห็นตัวอย่างเยอะ |

**เพิ่มข้อกำหนดนี้ในวิชาสังคม/ไทย/ประวัติศาสตร์:**
```
เนื้อหาที่เป็นข้อเท็จจริง (ปี พ.ศ. ชื่อบุคคล ชื่อสถานที่ ตัวบทกฎหมาย มาตรา)
ต้องระบุไว้ในฟิลด์ sources ว่าอ้างจากอะไร
และถ้าไม่มั่นใจในตัวเลขหรือชื่อ ให้เขียนกำกับใน notes ว่า "ต้องตรวจสอบ"
ห้ามเดาตัวเลขหรือชื่อให้ดูน่าเชื่อถือ
```
เพราะเรื่องพวกนี้ AI ผิดบ่อยที่สุด และเป็นเนื้อหาที่ผู้ใช้จะจำไปใช้ตอบข้อสอบ
