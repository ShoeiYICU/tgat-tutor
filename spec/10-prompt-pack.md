## เริ่มต้นใน 4 ขั้น

### ขั้น 1 — เปิดแชตใหม่ใน ChatGPT
เลือกโมเดลที่คิดเยอะที่สุดที่คุณมี **1 แชต = 1 วิชา** อย่าปนวิชาในแชตเดียว

### ขั้น 2 — แนบไฟล์ 3 ไฟล์นี้
| ไฟล์ | ทำไมต้องแนบ |
|---|---|
| `spec/03-schema.md` | ฟอร์แมต JSON ที่ต้องตอบ **ขาดไม่ได้** |
| `spec/01-overview.md` | กฎตั้งรหัส `topic_id` และกฎเขียน LaTeX |
| `data/topics/math.topics.json` | ตัวอย่างไฟล์ที่ถูกต้อง ให้ดูเป็นแบบ |

### ขั้น 3 — วาง prompt จากหัวข้อ A ด้านล่าง
หัวข้อ A กรอกเป็น **TGAT2** ไว้แล้ว ซึ่งเป็นวิชาที่ควรทำก่อนที่สุด คัดลอกทั้งกรอบไปวางได้เลยไม่ต้องแก้อะไร

### ขั้น 4 — ได้ไฟล์มาแล้ว
บันทึกเป็น `data/topics/<subject>.topics.json` แล้วรัน

```bash
python scripts/validate.py
```

ถ้าขึ้น `ต้องแก้` ให้ก๊อปข้อความ error กลับไปวางในแชตเดิม บอกว่า "แก้ตามนี้" — GPT แก้ได้เอง

# A. PROMPT สร้างผังหัวข้อ — ฉบับเต็ม (กรอกเป็น TGAT2 วิชาที่ทำก่อน)

คัดลอกทั้งกรอบ แล้ววางใน ChatGPT

```
คุณเป็นผู้เชี่ยวชาญข้อสอบเข้ามหาวิทยาลัยไทย (TCAS) และการออกแบบหลักสูตรติวสอบ

งานของคุณคือสร้าง "ผังหัวข้อ" (topic tree) ของวิชาสอบหนึ่ง เพื่อใช้เป็นกระดูกสันหลัง
ของเว็บไซต์ติวสอบ ผังนี้จะถูกอ้างถึงโดยบทเรียนและโจทย์ทุกข้อในภายหลัง
จึงต้องครบและตั้งรหัสให้นิ่งตั้งแต่ครั้งแรก

## วิชาที่ทำ
- subject: tgat2
- exam_code: TGAT2
- ชื่อวิชา: TGAT2 การคิดอย่างมีเหตุผล (Critical and Logical Thinking)
- โครงสร้าง (**ยืนยันแล้วจาก mytcas.com/blueprint/tgat2-92/** ให้ใช้เป็นข้อเท็จจริง):
  **80 ข้อ 100 คะแนน 60 นาที ปรนัย 5 ตัวเลือก** แบ่งเป็น 4 ด้าน ด้านละ 4 ส่วนย่อย
  (1) ความสามารถทางภาษา — การสื่อความหมาย / การใช้ภาษา / การอ่าน / การเข้าใจภาษา
  (2) ความสามารถทางตัวเลข — อนุกรมมิติ / การเปรียบเทียบเชิงปริมาณ / ความเพียงพอของข้อมูล
      / โจทย์ปัญหาเชิงปริมาณ
  (3) ความสามารถทางมิติสัมพันธ์ — การพับกล่อง / การหาภาพต่าง / การหมุนภาพสามมิติ
      / การประกอบภาพ
  (4) ความสามารถทางเหตุผล — อนุกรมภาพและสัญลักษณ์ / การสรุปความ / การวิเคราะห์ข้อความ
      / เงื่อนไขทางสัญลักษณ์

  ⚠️ ด้านมิติสัมพันธ์ **ไม่มี "ภาพตัดขวาง"** (เคยเข้าใจผิดกันบ่อย) ห้ามใส่เข้ามา
- ผู้เรียนเป้าหมาย: เด็กไทย ม.ปลาย ทุกสายการเรียน รวมสายศิลป์ที่คณิตอ่อน

## หมายเหตุพิเศษของวิชานี้
วิชานี้เป็นวิชาที่ทำโจทย์แม่แบบ (template) ได้ดีที่สุดในทุกวิชา เพราะโจทย์ส่วนใหญ่
สุ่มตัวเลขหรือสุ่มรูปแบบได้ ให้ซอย leaf ให้ละเอียดพอที่แต่ละ leaf จะมีรูปแบบโจทย์
ที่ชัดเจนแบบเดียว เช่น แยก "อนุกรมเลขแบบผลต่างคงที่" ออกจาก "อนุกรมเลขแบบคูณ"
เพราะสองอย่างนี้สร้างแม่แบบต่างกันและฝึกแยกกันได้

## สิ่งที่ต้องทำ
1. แตกวิชานี้เป็นผัง 3 ระดับ subject -> branch -> leaf ตามกฎในไฟล์ 03-schema.md ส่วน A
2. ครอบคลุมทุกสิ่งที่ผู้สอบต้องฝึก ไม่ตกหล่น ทั้ง
   - รูปแบบคำถามแต่ละแบบที่ออกสอบในวิชานี้ แยกเป็น leaf ต่อรูปแบบ
   - ทักษะพื้นฐานที่ต้องมีก่อนจึงทำข้อสอบรูปแบบนั้นได้
3. เพิ่มชั้นพื้นฐานที่ต่ำกว่าระดับข้อสอบด้วย ใส่ grade_band เป็น "m_early"
   เพราะเว็บนี้ต้องรองรับคนที่เริ่มจาก 0 จริง ๆ ไม่ใช่คนที่พื้นแน่นแล้ว
4. กำหนด requires ให้ถูกต้อง ใส่เฉพาะหัวข้อที่ "ถ้าไม่รู้แล้วเรียนหัวข้อนี้ไม่ได้จริง"
   ผังต้องไม่มีวงวน (เป็น DAG)
5. ขนาดของแต่ละ leaf ต้องสอนได้จบใน 10-30 นาที
   - อธิบายเกิน 30 นาที = ใหญ่เกินไป ให้ซอย
   - ออกโจทย์ฝึกได้ไม่ถึง 5 ข้อ = เล็กเกินไป ให้รวมกับหัวข้อข้างเคียง

## ข้อสำคัญเฉพาะวิชากลุ่ม TGAT/TPAT
วิชานี้ไม่ใช่วิชาเนื้อหาตามหลักสูตร แต่เป็นการวัด "ความถนัด/สมรรถนะ"
ดังนั้น leaf ควรเป็น **ทักษะหรือรูปแบบโจทย์ที่ฝึกได้** ไม่ใช่บทเรียนวิชาการ

เกณฑ์ตัดสินว่า leaf ใช้ได้: อ่านชื่อ leaf แล้วต้องตอบได้ทันทีว่า
"ออกโจทย์ฝึกเรื่องนี้ 10 ข้อได้ไหม" ถ้าตอบไม่ได้ แปลว่า leaf นั้นกว้างเกินไป ให้ซอย

ตัวอย่างที่ดี: "อนุกรมเลขแบบผลต่างคงที่", "การหมุนภาพสามมิติรอบแกนตั้ง"
ตัวอย่างที่ไม่ดี: "ความสามารถทางตัวเลข" (กว้างเกินไป ฝึกไม่ได้เป็นเรื่อง ๆ)

## ข้อห้าม
- ห้ามคิดชื่อฟิลด์เอง ใช้ฟิลด์ตาม 03-schema.md ส่วน A.2 เท่านั้น และต้องใส่ครบทุกฟิลด์
- ห้ามยืนยันจำนวนข้อ เวลา หรือสัดส่วนคะแนน ว่าเป็นข้อเท็จจริง
  ถ้าคุณไม่มั่นใจโครงสอบ ให้เขียนสิ่งที่ไม่มั่นใจไว้ในฟิลด์ notes ของ branch นั้น
  ผมจะไปตรวจกับ mytcas.com เอง
- ห้ามแต่งตัวเลข frequency ให้ดูน่าเชื่อ ไม่มีข้อมูลจริงให้ใส่ confidence เป็น "low"
- ห้ามใส่ข้อความอธิบายนอก JSON

## รูปแบบคำตอบ
JSON ตาม 03-schema.md ส่วน A.1 เท่านั้น
ถ้ายาวเกินตอบรอบเดียว ให้แบ่งตอบทีละ branch ขึ้นต้นว่า "ส่วนที่ N / ทั้งหมด M"
แล้วตอบเฉพาะอาร์เรย์ topics ของ branch นั้น ผมจะพิมพ์ว่า "ต่อ" เพื่อขอส่วนถัดไป
รอบสุดท้ายให้สรุปว่ามี leaf ทั้งหมดกี่อัน

## ก่อนตอบ ให้ตรวจตัวเองว่า
- ทุก parent ที่อ้างถึงมีอยู่ในผังจริง และ parent ไม่ใช่ leaf
- ไม่มี id ซ้ำ และ id ใช้แต่ a-z 0-9 _ คั่นชั้นด้วยจุด
- requires ไม่ชี้ไปหา id ที่ไม่มีอยู่ และไม่มีวงวน
- ทุก leaf มี est_minutes อยู่ระหว่าง 10-30
- leaf ที่ไม่มี requires เลย ไม่ควรเกิน 30% ของ leaf ทั้งหมด
```

# B. วิชาถัดไป — เปลี่ยนแค่บล็อก `## วิชาที่ทำ`

prompt ส่วนอื่นเหมือนเดิมทุกตัวอักษร ให้เปลี่ยนเฉพาะบล็อก `## วิชาที่ทำ` ด้วยบล็อกด้านล่าง

> ⚠️ โครงสร้างที่เขียนไว้ทุกวิชาเป็น **จุดเริ่มต้น ไม่ใช่ข้อเท็จจริงที่ยืนยันแล้ว**
> จำนวนข้อ เวลา และสัดส่วน ต้องไปตรวจกับ mytcas.com และประกาศ ทปอ. ด้วยตัวเอง
> (สำหรับ TPAT1 ตรวจกับประกาศ กสพท) — prompt สั่งให้ GPT ไม่ยืนยันตัวเลขพวกนี้ไว้แล้ว

```
- exam_code: TGAT1
- ชื่อวิชา: TGAT1 การสื่อสารภาษาอังกฤษ (English Communication)
- โครงสร้างตั้งต้น (ผมยังไม่ยืนยัน ให้คุณใช้เป็นจุดเริ่ม ไม่ใช่ข้อเท็จจริง):
  ประมาณ 60 ข้อ 100 คะแนน 60 นาที แบ่งเป็น
  (1) ทักษะการพูด (Speaking) — question-response, short conversation, long conversation
  (2) ทักษะการอ่าน (Reading) — ป้าย/ประกาศ/โฆษณา, บทความ, บทอ่านยาว
- ผู้เรียนเป้าหมาย: เด็กไทย ม.ปลาย ที่พื้นฐานอังกฤษอ่อน เริ่มจาก 0 ได้

## หมายเหตุพิเศษของวิชานี้
ข้อสอบวัดการใช้ภาษาในสถานการณ์จริง ไม่ใช่การท่องกฎไวยากรณ์
leaf จึงต้องเป็นทักษะที่ฝึกได้ เช่น "การตอบรับคำขอร้องในบทสนทนา"
"การเดาความหมายศัพท์จากบริบท" "การหาใจความสำคัญของย่อหน้า"
ไม่ใช่ leaf แบบ "Present Perfect" ซึ่งเป็นการมองแบบวิชาไวยากรณ์

ต้องมีชั้นพื้นฐานสำหรับคนที่อังกฤษอ่อนจริง ๆ ด้วย (grade_band เป็น "m_early")
เช่น คำศัพท์กลุ่มที่ใช้บ่อยในบทสนทนา โครงสร้างประโยคพื้นฐาน การอ่านจับใจความเบื้องต้น
```

## B.2 TGAT3 — สมรรถนะการทำงาน

```
## วิชาที่ทำ
- subject: tgat3
- exam_code: TGAT3
- ชื่อวิชา: TGAT3 สมรรถนะการทำงาน (Future Workforce Competencies)
- โครงสร้างตั้งต้น (ผมยังไม่ยืนยัน ให้คุณใช้เป็นจุดเริ่ม ไม่ใช่ข้อเท็จจริง):
  ประมาณ 60 ข้อ 100 คะแนน 60 นาที แบ่งเป็น 4 ด้าน
  (1) การสร้างคุณค่าและนวัตกรรม
  (2) การแก้ไขปัญหาซับซ้อน
  (3) การบริหารจัดการอารมณ์
  (4) การเป็นพลเมืองที่มีส่วนร่วมของสังคม
  ข้อสอบเป็นแบบสถานการณ์ (situational judgement) ให้เลือกหรือจัดลำดับว่าควรทำอะไร
- ผู้เรียนเป้าหมาย: เด็กไทย ม.ปลาย ที่ไม่เคยทำงานจริง จึงไม่มีประสบการณ์เป็นฐาน

## หมายเหตุพิเศษของวิชานี้
วิชานี้ไม่มีคำตอบถูกทางคณิตศาสตร์ วัดการตัดสินใจในสถานการณ์
ดังนั้น leaf ต้องเป็น "ประเภทสถานการณ์และเกณฑ์ตัดสินที่ใช้" ที่ฝึกได้จริง เช่น
"สถานการณ์ความขัดแย้งในทีม: เกณฑ์เลือกลำดับการจัดการ"
ไม่ใช่ leaf กว้าง ๆ แบบ "การบริหารอารมณ์"

สิ่งที่ผู้สอบต้องได้จากบทเรียนของวิชานี้คือ **เกณฑ์ที่ผู้ออกข้อสอบใช้ตัดสินว่าอะไรเหมาะสมกว่า**
เช่น ให้ความสำคัญกับความปลอดภัยก่อนประสิทธิภาพ สื่อสารตรงไปตรงมาแต่รักษาความสัมพันธ์
แก้ที่ระบบไม่ใช่ตัวบุคคล ให้ใส่เกณฑ์เหล่านี้เป็น leaf ด้วย ไม่ใช่มีแต่ประเภทสถานการณ์
```

```
## วิชาที่ทำ

- ชื่อวิชา: TPAT1 วิชาเฉพาะ กสพท (แพทยศาสตร์ ทันตแพทยศาสตร์ สัตวแพทยศาสตร์ เภสัชศาสตร์)
- โครงสร้างตั้งต้น (ผมยังไม่ยืนยัน ให้คุณใช้เป็นจุดเริ่ม ไม่ใช่ข้อเท็จจริง):
  แบ่งเป็น 3 ส่วน
  (1) เชาวน์ปัญญา — อนุกรม ตรรกศาสตร์ มิติสัมพันธ์ คำนวณ ภาษา
  (2) จริยธรรมทางการแพทย์ — สถานการณ์ที่ต้องตัดสินใจเชิงจริยธรรม

## หมายเหตุพิเศษของวิชานี้
```

# C. รอบที่ 2 — ให้ AI อีกตัวตรวจผัง (ทำทุกวิชา ก่อนล็อกรหัส)

เปิดแชตใหม่ ถ้าทำได้ให้ใช้ AI **ต่างค่าย** จากตัวที่สร้างผัง

```
นี่คือผังหัวข้อวิชา <<ชื่อวิชา>> สำหรับข้อสอบ <<exam_code>> ที่ร่างขึ้นด้วย AI
โปรดตรวจอย่างเข้มงวดในฐานะผู้เชี่ยวชาญข้อสอบ TCAS
รายงานเป็นตาราง ไม่ต้องเขียน JSON ใหม่

ตรวจ 7 ข้อ
1. หัวข้อที่ออกสอบจริงแต่ขาดไป
2. หัวข้อที่ไม่อยู่ในขอบเขตข้อสอบนี้แต่ใส่มา
3. leaf ที่ใหญ่เกินไป (สอนไม่จบใน 30 นาที) — บอกว่าควรซอยเป็นอะไร
4. leaf ที่เล็กเกินไปหรือกว้างจนฝึกไม่ได้ — บอกว่าควรรวมหรือซอยเป็นอะไร

6. ชื่อหัวข้อที่ใช้ศัพท์ไม่ตรงกับที่ใช้ในวงการศึกษาไทย
7. หัวข้อพื้นฐานที่คนเริ่มจาก 0 ต้องรู้ก่อน แต่ผังไม่มี

ตอบเป็นตาราง: [ข้อที่] [topic_id ที่เกี่ยว] [ปัญหา] [ควรแก้เป็น] [ความสำคัญ สูง/กลาง/ต่ำ]

<<วาง JSON ผังหัวข้อ>>
```

```
## ข้อกำหนดเพิ่มสำหรับวิชากลุ่ม TGAT/TPAT
วิชานี้ไม่ใช่วิชาเนื้อหา บทเรียนจึงต้องสอน "วิธีคิดและเทคนิคทำโจทย์" ไม่ใช่ความรู้วิชาการ
- บล็อก formula ให้ใช้เก็บ "หลักการหรือขั้นตอนการคิด" แทนสูตร
  ใส่ formula_tex เป็น "" แล้วเขียนขั้นตอนใน name และเงื่อนไขการใช้ใน use_when/avoid_when
- บล็อก example ต้องแสดงกระบวนการคิดตั้งแต่อ่านโจทย์ ไม่ใช่เริ่มที่การคำนวณ
  ขั้นแรกของทุกตัวอย่างควรเป็น "อ่านโจทย์แล้วรู้ได้อย่างไรว่าเป็นโจทย์ประเภทนี้"
- บล็อก pitfall ต้องเป็นกับดักที่ผู้ออกข้อสอบวางไว้จริง
- เพิ่ม example เป็น 4-5 บล็อก เพราะวิชาแบบนี้เรียนจากการเห็นตัวอย่างเยอะ
- ถ้าเป็นข้อสอบสถานการณ์ (TGAT3, TPAT1 จริยธรรม, TPAT5 คุณลักษณะครู)
  เฉลยต้องอธิบาย **เกณฑ์ตัดสิน** ว่าทำไมตัวเลือกนี้เหมาะสมกว่า ไม่ใช่บอกว่าถูกเพราะถูก
```
