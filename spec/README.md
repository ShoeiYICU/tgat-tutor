# ชุดเอกสารสำหรับสร้างเนื้อหาและโจทย์ (Content Pipeline Spec)

โฟลเดอร์นี้คือ "คู่มือสั่งงาน AI" สำหรับผลิตข้อมูลของเว็บไซต์ติวสอบเข้ามหาวิทยาลัยไทย
ไฟล์ในนี้ **ไม่ใช่โค้ด** เป็นเอกสารที่เอาไปแนบให้ ChatGPT / Codex / Claude ทำงานต่อได้ทันที

---

## เว็บนี้มี 3 ฟีเจอร์ที่แยกกันชัดเจน

| | ฟีเจอร์ A — **คลังเนื้อหา (Learn)** | ฟีเจอร์ B — **คลังโจทย์ (Practice)** |
|---|---|---|
| ใครใช้ | คนที่เริ่มจาก 0 ไม่มีเงินเรียนคอร์ส | คนที่มีพื้นแล้ว อยากลองวัดตัวเอง |
| ได้อะไร | บทเรียนอ่านเอง เรียนจบได้โดยไม่ต้องพึ่งแอปอื่น | โจทย์จริง + โจทย์ที่ระบบสร้างใหม่ให้ยากเท่ากัน + จับเวลา + วิเคราะห์ผล |
| เข้าใช้แยกกัน | ได้ ไม่ต้องทำโจทย์ก็เรียนได้ | ได้ ไม่ต้องอ่านเนื้อหาก็ทำโจทย์ได้ |
| สิ่งที่แชร์กัน | **`topic_id` ชุดเดียวกัน** | **`topic_id` ชุดเดียวกัน** |

### ฟีเจอร์ C — คลังข้อสอบจริง (Past Papers)

| | รายละเอียด |
|---|---|
| ใครใช้ | คนที่อยากเห็นว่าข้อสอบจริงหน้าตาเป็นอย่างไร ถามแบบไหน ยากแค่ไหน |
| ได้อะไร | ข้อสอบจริงย้อนหลัง + เฉลยที่เราเขียนเอง + สถิติว่าหัวข้อไหนออกบ่อย |
| ต่างจากฟีเจอร์ B | ข้อสอบจริง = **ดูของจริง** (ทำซ้ำแล้วจำคำตอบได้) / โจทย์ที่สร้างใหม่ = **ฝึกซ้ำได้ไม่จำกัด** |
| เชื่อมกันยังไง | ทุกข้อของข้อสอบจริงมีปุ่ม "ฝึกแนวนี้" ที่ส่งไปโจทย์แม่แบบของหัวข้อเดียวกัน |
| ⚠️ ข้อควรระวัง | **ห้ามให้ AI นึกข้อสอบจริงออกมาเอง** มันจะแต่งขึ้นแล้วอ้างว่าเป็นของจริง — อ่าน `09-real-exam-papers.md` ข้อ 0 ก่อนเริ่ม |

รายละเอียดทั้งหมดอยู่ใน [09-real-exam-papers.md](09-real-exam-papers.md)

> **ทำไมต้องแชร์ `topic_id`**
> สองฟีเจอร์นี้แยกกันในสายตาผู้ใช้ (เมนูแยก หน้าแยก ใช้อย่างเดียวก็จบ)
> แต่ในฐานข้อมูลต้องอ้างหัวข้อด้วยรหัสเดียวกัน ไม่งั้นวันหลังจะทำ "ทำโจทย์ผิด → กดไปอ่านเนื้อหาเรื่องนั้น"
> หรือ "อ่านจบ → ลองทำโจทย์เรื่องนี้" ไม่ได้เลย ต้องกลับมา tag ใหม่ทั้งหมด
> **ค่าใช้จ่ายของการแชร์ `topic_id` ตอนนี้ = 0 ค่าใช้จ่ายของการไม่ทำ = รื้อใหม่ทั้งระบบ**

## ตอบคำถาม: ควรใช้ ChatGPT หรือ Codex?

**ใช้ทั้งคู่ แต่คนละหน้าที่ อย่าสลับกัน**

### ChatGPT (เลือกโมเดลที่คิดเยอะ เช่น GPT-5 Thinking) → ใช้ผลิต "เนื้อหาและโจทย์"
เหมาะเพราะงานนี้คือการคิดวิชาการ ไม่ใช่การเขียนโค้ด
- สร้างผังหัวข้อ (topic tree)
- เขียนบทเรียน
- แต่งโจทย์ + เฉลย + ตัวเลือกลวง
- วิธีใช้: เปิดแชตใหม่ต่อ 1 วิชา → แนบ `03-schema.md` + `02-exam-map.md` (ส่วนวิชานั้น) → วาง prompt จากไฟล์ 04/05/06 → สั่งทีละหัวข้อ

### Codex (หรือ Claude Code) → ใช้ทำ "ระบบ" ไม่ใช่เนื้อหา
- เขียนสคริปต์ตรวจไฟล์ JSON ว่าตรง schema ไหม (validator)
- เขียนสคริปต์ยิง API ผลิตเนื้อหาทีละหลายร้อยหัวข้อ
- เขียนตัวเว็บ + ระบบสร้างโจทย์จาก template + ระบบนำเข้าข้อมูล

### สคริปต์ตรวจงาน (เขียนเสร็จแล้ว ใช้ได้เลย)

| คำสั่ง | ทำอะไร |
|---|---|
| `python scripts/validate.py` | **ชั้นที่ 1** ตรวจฟอร์แมตทุกไฟล์ใน `data/` |
| `python scripts/render_template.py --stress` | **ชั้นที่ 2** รันแม่แบบข้อละ 200 ครั้ง หาโจทย์ที่พัง |
| `python scripts/render_template.py --show <topic_id> --full` | ดูโจทย์ที่สุ่มได้ พร้อมวิธีคิดและคำใบ้ |
| `python scripts/selftest.py` | ตรวจว่าตัวตรวจทั้งสองชั้นยังจับข้อผิดพลาดได้ครบ |
| `python scripts/sync_status.py` | อัปเดต `data/_status.csv` จากผังหัวข้อ |
| `python scripts/cube_net.py` | ตรวจแผ่นคลี่ลูกบาศก์ทุกแบบว่าพับได้จริงและครบ 11 รูปทรง |

รันสองคำสั่งแรกทุกครั้งที่ได้ไฟล์ใหม่ ก่อนเอาไปตรวจด้วยคน
ถ้าแก้ตัวสคริปต์เองให้รัน `selftest.py` ด้วย
รายละเอียดอยู่ใน [08-workflow.md](08-workflow.md)

### ตัวผลิตเป็นชุด `scripts/generate.py`

ยิง Claude API ผลิตบทเรียน/โจทย์เป็นชุด แล้ว **บังคับให้ผ่านตัวตรวจทั้งสองชั้นก่อนเข้า `data/`**
ของที่ไม่ผ่านไปอยู่ `data/_generate/rejected/` พร้อมผลตรวจ

ไฟล์นี้เป็นตัวเดียวที่ต้องติดตั้งเพิ่ม (`pip install anthropic`) — ตัวตรวจงานทุกตัวยังใช้
ไลบรารีมาตรฐานล้วน จึงรันได้ทุกเครื่องโดยไม่ต้องติดตั้งอะไร

```
python scripts/generate.py --plan                          ดูว่าค้างอะไร (ไม่เสียเงิน)
python scripts/generate.py --topic <id> --kind lesson --dry-run   ประเมินค่าใช้จ่าย (ไม่เสียเงิน)
python scripts/generate.py --kind problems --batch --limit 20     ยิงเป็นชุด (ครึ่งราคา)
```

รายละเอียดอยู่ใน [08-workflow.md](08-workflow.md) ข้อ 7.1

โฟลเดอร์ `scripts/providers/` คือโค้ดเฉพาะทางที่แม่แบบเรียกใช้ได้
ใช้กับหัวข้อที่คำตอบไม่ใช่ตัวเลขหรือโจทย์ต้องมีรูปที่สร้างจากค่าที่สุ่ม (ดู `03-schema.md` ข้อ C.6)

### สิ่งที่ห้ามทำ
- **ห้ามให้ AI ออกแบบฟอร์แมตข้อมูลเอง** — มันจะเปลี่ยนชื่อฟิลด์ทุกครั้งที่คุณถามใหม่ แล้วข้อมูลจะนำเข้าไม่ได้ ให้ยึด `03-schema.md` เป็นกฎตายตัว
- **ห้ามสั่งทีเดียวทั้งวิชา** เช่น "เขียนบทเรียนคณิต ม.ปลาย ทั้งหมด" — จะได้ของตื้นและเฉลยผิด ให้สั่ง **ทีละ 1 หัวข้อย่อย** เท่านั้น
- **ห้ามเชื่อเฉลยที่ AI ให้มาโดยไม่ตรวจ** — ดูวิธีตรวจใน `07-quality-and-legal.md`

### ข้อเท็จจริงเรื่องปริมาณงาน (ต้องรู้ก่อนเริ่ม)
ครอบคลุม "ทุกวิชา" จริง ๆ จะมีประมาณ **1,500–2,500 หัวข้อย่อย**
- ถ้า copy-paste ใน ChatGPT ด้วยมือ: หัวข้อละ ~5 นาที = **125–210 ชั่วโมง** ต่อรอบ (ยังไม่นับตรวจ)
- ทางที่ควรทำ: ใช้มือทำ **20–30 หัวข้อแรก** เพื่อจูน prompt ให้คุณภาพนิ่ง → แล้วให้ Codex เขียนสคริปต์ยิง API ทำที่เหลือ
- อ่านรายละเอียดใน `08-workflow.md` หัวข้อ "โหมดผลิตจำนวนมาก"
