# 04 — Prompt สำเร็จรูป: สร้างผังหัวข้อ (Topic Tree)

**ทำขั้นนี้ก่อนทุกอย่าง** ทั้งบทเรียนและโจทย์ต้องอ้าง `topic_id` จากผังนี้

## วิธีใช้
1. เปิดแชตใหม่ใน ChatGPT (เลือกโมเดลที่คิดเยอะ เช่น GPT-5 Thinking) **1 แชต = 1 วิชา**
2. แนบไฟล์ `03-schema.md` และ `01-overview.md`
3. คัดลอกข้อความในกรอบด้านล่างไปวาง แก้เฉพาะช่องที่มี `<< >>`
4. ได้ผลแล้วบันทึกเป็น `data/topics/<subject>.topics.json`

## PROMPT — คัดลอกทั้งกรอบนี้

```
คุณเป็นผู้เชี่ยวชาญหลักสูตรมัธยมศึกษาไทยและข้อสอบเข้ามหาวิทยาลัย (TCAS)
งานของคุณคือสร้าง "ผังหัวข้อ" (topic tree) ของวิชาหนึ่ง เพื่อใช้เป็นกระดูกสันหลังของเว็บไซต์ติวสอบ

## วิชาที่ทำ
- subject: <<math>>
- ชื่อวิชา: <<คณิตศาสตร์>>
- สนามสอบที่เกี่ยวข้อง: <<ALEVEL_61 คณิตศาสตร์ประยุกต์ 1>>
- ขอบเขต: <<สาระพื้นฐานและสาระเพิ่มเติม ม.4-ม.6 ตามหลักสูตรแกนกลาง 2551 (ฉบับปรับปรุง 2560)>>

## สิ่งที่ต้องทำ
1. แตกวิชานี้เป็นผัง 3 ระดับ: subject -> branch -> leaf ตามกฎในไฟล์ 03-schema.md ส่วน A
2. ครอบคลุม **ทุกหัวข้อที่ออกสอบได้** ไม่ตกหล่น
3. เพิ่มชั้นพื้นฐาน ม.ต้น ที่จำเป็นด้วย (ใส่ grade_band เป็น "m_early")
   เพราะเว็บนี้ต้องรองรับคนที่เริ่มเรียนจาก 0 จริง ๆ
4. กำหนด requires ให้ถูกต้อง โดยใส่เฉพาะหัวข้อที่ "ไม่รู้แล้วเรียนต่อไม่ได้จริง"
   ผังต้องไม่มีวงวน (DAG)
5. ขนาดของแต่ละ leaf ต้องสอนได้จบใน 10-30 นาที
   - ถ้าอธิบายเกิน 30 นาที ให้ซอยเป็นหลาย leaf
   - ถ้าออกโจทย์ได้ไม่ถึง 5 ข้อ ให้รวมกับหัวข้อข้างเคียง

## ข้อห้าม
- ห้ามคิดชื่อฟิลด์เอง ใช้ฟิลด์ตาม 03-schema.md ส่วน A.2 เท่านั้น ครบทุกฟิลด์
- ห้ามแต่งตัวเลข frequency ให้ดูน่าเชื่อ ถ้าไม่มีข้อมูลจริงให้ใส่ confidence เป็น "low"
- ห้ามใส่ข้อความอธิบายนอก JSON

## รูปแบบคำตอบ
ตอบเป็น JSON ตาม 03-schema.md ส่วน A.1 เท่านั้น
ถ้าเนื้อหายาวเกินกว่าจะตอบรอบเดียว ให้แบ่งตอบตาม branch ทีละ branch
โดยขึ้นต้นแต่ละรอบว่า "ส่วนที่ N / ทั้งหมด M" และตอบ JSON เฉพาะอาร์เรย์ topics ของ branch นั้น
ผมจะพิมพ์ว่า "ต่อ" เพื่อขอส่วนถัดไป

## ก่อนตอบ ให้ตรวจตัวเองว่า
- ทุก parent ที่อ้างถึง มีอยู่ในผังจริง
- ไม่มี id ซ้ำ
- requires ไม่ชี้ไปหา id ที่ไม่มีอยู่ และไม่มีวงวน
- ทุก leaf มี est_minutes อยู่ระหว่าง 10-30
```

## รอบที่ 2 — ให้ AI ตรวจงานตัวเอง (ทำด้วย โมเดลอื่น จะดีกว่า)

พอได้ผังมาแล้ว **เปิดแชตใหม่** (ถ้าทำได้ให้ใช้ AI อีกตัว เช่น Claude ตรวจงานของ GPT)
แล้วใช้ prompt นี้:

```
นี่คือผังหัวข้อวิชา <<คณิตศาสตร์>> สำหรับข้อสอบ <<A-Level 61>> ที่ร่างขึ้นด้วย AI
โปรดตรวจสอบอย่างเข้มงวดและรายงานเป็นรายการ ไม่ต้องเขียน JSON ใหม่

ตรวจ 6 ข้อนี้
1. หัวข้อที่ออกสอบจริงแต่ "ขาดไป" — ระบุเป็นรายการ
2. หัวข้อที่ "ไม่อยู่ในขอบเขต" ของข้อสอบนี้แต่ใส่มา — ระบุเป็นรายการ
3. leaf ที่ใหญ่เกินไป (สอนไม่จบใน 30 นาที) — บอกว่าควรซอยเป็นอะไร
4. leaf ที่เล็กเกินไป — บอกว่าควรรวมกับอะไร
5. requires ที่ผิด: ใส่เกินจำเป็น, ขาดไป, หรือมีวงวน
6. ชื่อหัวข้อที่ใช้ศัพท์ไม่ตรงกับที่ สสวท./กระทรวงศึกษาฯ ใช้

ตอบเป็นตาราง: [ปัญหา] [topic_id ที่เกี่ยว] [ควรแก้เป็นอะไร] [ความสำคัญ สูง/กลาง/ต่ำ]

<<วาง JSON ผังหัวข้อที่นี่>>
```

---

## เกณฑ์ว่าผังหัวข้อ "ใช้ได้แล้ว"

| เกณฑ์ | ค่าที่ควรได้ |
|---|---|
| จำนวน leaf ต่อ 1 วิชาหลัก (คณิต ฟิสิกส์ เคมี ชีวะ) | 80–200 |
| จำนวน leaf ต่อ 1 วิชาภาษา/สังคม | 40–120 |
| จำนวน leaf ต่อ 1 พาร์ท TGAT/TPAT | 15–50 |
| leaf ที่ไม่มี `requires` เลย | ไม่ควรเกิน 30% (ถ้าเกิน = ยังไม่ได้คิดเรื่องพื้นฐาน) |
| ความลึกของผัง | 3–4 ชั้น |

> **ผังหัวข้อคือสิ่งที่แก้ยากที่สุดภายหลัง** เพราะบทเรียนและโจทย์ทั้งหมดอ้างรหัสจากมัน
> ยอมเสียเวลาตรวจผังให้ดีตั้งแต่ตอนนี้ 1 วัน ดีกว่าต้องมา tag ใหม่ 2,000 ข้อทีหลัง
