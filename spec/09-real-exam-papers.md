# 09 — คลังข้อสอบจริง (ฟีเจอร์ C)

> ไฟล์นี้เพิ่มเข้ามาเมื่อตัดสินใจว่า **เว็บจะแสดงข้อสอบจริงด้วย** ไม่ใช่แค่โจทย์ที่ระบบสร้างขึ้น
> ฟีเจอร์ A (เนื้อหา) และ B (โจทย์ที่สร้างใหม่) ไม่เปลี่ยน ของเดิมใช้ได้ทั้งหมด

---

## 0. ข้อที่ต้องอ่านก่อนอย่างอื่น — กับดักที่อันตรายที่สุดของฟีเจอร์นี้

### ห้ามให้ AI "นึก" ข้อสอบจริงออกมาเด็ดขาด

ถ้าคุณสั่ง ChatGPT ว่า *"รวบรวมข้อสอบ A-Level คณิต ปี 2567 มาให้ครบ 30 ข้อ"*
มันจะตอบมาครบ 30 ข้อ ดูน่าเชื่อถือทุกข้อ และ **เกือบทั้งหมดจะไม่ใช่ข้อสอบจริง**
เพราะโมเดลไม่ได้จำข้อสอบไว้ทีละข้อ มันจะ "แต่งขึ้นในสไตล์ข้อสอบ" แล้วนำเสนอเหมือนเป็นของจริง

ผลที่ตามมาแย่กว่าทุกกรณี:
- เว็บของคุณจะมีหน้า "ข้อสอบจริงปี 2567" ที่เป็นของปลอม → พอมีเด็กเทียบกับต้นฉบับ ความเชื่อถือพังทั้งเว็บ
- แย่กว่าการไม่มีข้อสอบจริงเลย และแย่กว่าการมีโจทย์ที่บอกตรง ๆ ว่าแต่งขึ้น
- validator จับไม่ได้ เพราะฟอร์แมตถูกทุกอย่าง ผิดแค่ "มันไม่ใช่ของจริง"

**กฎ:** ตัวโจทย์ของข้อสอบจริงต้องมาจาก **ไฟล์ต้นฉบับที่คุณมีอยู่จริง** เท่านั้น
AI มีหน้าที่แค่ **ถอดจากไฟล์** และ **วิเคราะห์** ไม่ใช่ผู้ให้ข้อมูล

| งานเกี่ยวกับข้อสอบจริง | ใครทำได้ |
|---|---|
| หาไฟล์ข้อสอบต้นฉบับ | **คุณ** เท่านั้น |
| ถอดข้อความจากไฟล์เข้าสู่ฟอร์แมต JSON | AI ได้ (จากไฟล์ที่แนบ) |
| tag ว่าแต่ละข้อเป็นหัวข้ออะไร ยากระดับไหน | AI ได้ |
| เขียนเฉลยและคำอธิบาย **ของเราเอง** | AI ได้ |
| วิเคราะห์ว่าปีนี้ออกหัวข้ออะไรกี่ข้อ | AI ได้ |
| **บอกว่าข้อสอบปีนั้นถามอะไร โดยไม่มีไฟล์** | **ห้าม** |

## 1. ออกแบบให้เปลี่ยนใจภายหลังได้ (สำคัญกว่าการตัดสินใจตอนนี้)

ข้อสอบ TGAT/TPAT/A-Level มีลิขสิทธิ์ของ ทปอ./สทศ. การแสดงทั้งชุดบนเว็บสาธารณะมีความเสี่ยง
ผมเคยเตือนแล้วและคุณตัดสินใจว่าจะทำ — งั้นสิ่งที่ผมทำได้ดีที่สุดคือ
**ออกแบบให้คุณเปลี่ยนระดับการเปิดเผยได้ทีหลังโดยไม่ต้องรื้อข้อมูล**

วิธีคือ ทุกชุดข้อสอบมี 2 ฟิลด์คุมการแสดง:

| ฟิลด์ | ค่า | ความหมาย |
|---|---|---|
| `license_status` | `official_public` | หน่วยงานเผยแพร่เอง (ตัวอย่างข้อสอบ/ข้อสอบเก่าที่ ทปอ. หรือ สทศ. ปล่อยเอง) — ปลอดภัยสุด |
| | `permission_granted` | ได้รับอนุญาตเป็นลายลักษณ์อักษร |
| | `unknown` | ไม่ทราบที่มาของสิทธิ์ — **ค่าเริ่มต้น** |
| | `restricted` | รู้ว่าห้ามเผยแพร่ |
| `visibility` | `public` | ใครก็ดูได้ |
| | `logged_in` | ต้องสมัครสมาชิกก่อนดู |
| | `internal_only` | เก็บไว้ใช้ภายในเพื่อวิเคราะห์ ไม่แสดงบนเว็บ |

**ค่าเริ่มต้นที่ผมแนะนำ:** `license_status: "unknown"` + `visibility: "internal_only"`
แล้วเปิดเป็น `public` เฉพาะชุดที่ `license_status` เป็น `official_public`

ทำแบบนี้แล้ว:
- คุณได้ประโยชน์ 100% จากข้อสอบจริงทันที (วิเคราะห์ผังการออกสอบ คาลิเบรตความยาก เขียนเฉลย)
- วันไหนอยากเปิดเพิ่ม/ปิด = แก้ค่าฟิลด์เดียว ไม่ต้อง tag ใหม่
- ถ้ามีหนังสือแจ้งให้ลบ = ปิดชุดนั้นได้ในคลิกเดียว ไม่กระทบชุดอื่น

> เอกสารนี้ไม่ใช่คำแนะนำทางกฎหมาย ถ้าเว็บเริ่มมีรายได้ ควรให้นักกฎหมายดูหนึ่งรอบ

## 2. ข้อสอบจริงกับโจทย์ที่สร้างใหม่ ทำหน้าที่ต่างกัน (นี่คือจุดขาย)

| | ข้อสอบจริง (ฟีเจอร์ C) | โจทย์ที่สร้างใหม่ (ฟีเจอร์ B) |
|---|---|---|
| ใช้ทำอะไร | **ดูของจริง** รู้ว่าข้อสอบหน้าตาแบบไหน ถามยังไง ยากแค่ไหน | **ฝึกซ้ำ** ได้ไม่จำกัดครั้ง |
| ทำซ้ำได้ไหม | ทำรอบสองก็จำคำตอบได้แล้ว | สุ่มเลขใหม่ทุกครั้ง จำไม่ได้ |
| ใช้ในระบบทบทวน | ไม่ | ใช่ |

**การเชื่อมสองอันนี้คือฟีเจอร์ที่เว็บอื่นทำไม่ได้:**

```
ดูข้อสอบจริงปี 2567 ข้อ 12  →  ทำไม่ได้ / อยากฝึกเพิ่ม
    → กด "ฝึกแนวนี้"  →  ระบบสุ่มโจทย์แม่แบบของหัวข้อเดียวกันให้ไม่จำกัดข้อ
    → ยังพลาด  →  กด "อ่านเนื้อหาเรื่องนี้" (ฟีเจอร์ A)
```

สิ่งที่ทำให้ทำได้คือฟิลด์ `topic_ids` และ `practice_template_ref` ในข้อ 3

## 3. ฟอร์แมตข้อมูล

**ไฟล์:** `data/exams/<exam_code>.<ปี>.json` เช่น `data/exams/ALEVEL_61.2567.json`
**ไฟล์ต้นฉบับ:** เก็บแยกที่ `data/exams/raw/` (ไม่ขึ้นเว็บ)

### 3.1 โครงไฟล์ `exam_paper`

| ฟิลด์ | ชนิด | คำอธิบาย |
|---|---|---|
| `schema_version` * | string | `"1.0"` |
| `exam_code` * | string | เช่น `"ALEVEL_61"` |
| `year` * | int | ปี พ.ศ. ของการสอบ |
| `round` * | string หรือ null | รอบสอบ ถ้ามีหลายรอบ |
| `paper_title` * | string | ชื่อที่แสดงบนเว็บ |
| `source` * | object | ที่มา ดูข้อ 3.2 |
| `license_status` * | enum | `official_public` / `permission_granted` / `unknown` / `restricted` |
| `visibility` * | enum | `public` / `logged_in` / `internal_only` |
| `transcription_status` * | enum | `raw` (AI ถอดมา ยังไม่ตรวจ) / `checked` (คนเทียบต้นฉบับแล้ว) |
| `structure` * | object | `{"num_items":30,"duration_min":90,"scoring_note":"..."}` |
| `items` * | object[] | รายข้อ ดูข้อ 3.3 |

### 3.2 `source`

```json
"source": {
  "kind": "official_release",
  "source_name": "เว็บไซต์ ทปอ.",
  "source_url": "https://...",
  "retrieved_date": "2026-09-19",
  "file_ref": "data/exams/raw/alevel61_2567.pdf",
  "note": null
}
```
`kind` = `official_release` / `user_provided_file` / `community_transcript`

**ถ้าไม่มี `file_ref` หรือ `source_url` ที่ตรวจย้อนได้ ห้ามตั้ง `transcription_status` เป็น `checked`**

### 3.3 `exam_item` (รายข้อ)

| ฟิลด์ | ชนิด | คำอธิบาย |
|---|---|---|
| `item_no` * | int | เลขข้อตามต้นฉบับ |
| `verbatim` * | bool | `true` = ถอดตรงตามต้นฉบับ / `false` = สรุปใจความ (ใช้เมื่อเลี่ยงการคัดลอกทั้งข้อ) |
| `stem_md` * | string หรือ null | ตัวโจทย์ — `null` ได้ถ้ายังไม่ได้ถอด หรือชุดนี้ `internal_only` แบบไม่เก็บตัวโจทย์ |
| `figures` * | object[] | ตามฟอร์แมต `03-schema.md` ข้อ B.3 |
| `choices` * | object[] หรือ null | ตัวเลือกตามต้นฉบับ |
| `official_answer` * | string หรือ null | เฉลยทางการ ถ้ามีประกาศ |
| `answer_source` * | enum | `official_key` (เฉลยทางการ) / `our_solution` (เราหาเอง) / `unknown` |
| `topic_ids` * | string[] | **หัวใจของการเชื่อมระบบ** ต้องเป็น `topic_id` ที่มีจริงในผังหัวข้อ |
| `primary_topic_id` * | string | หัวข้อหลัก |
| `difficulty` * | int 1–5 | ตามเกณฑ์ `03-schema.md` ข้อ C.3 |
| `difficulty_signals` * | object | ตาม `03-schema.md` ข้อ C.3 |
| `our_solution_steps` * | object[] | **เฉลยที่เราเขียนเอง** `[{"do_md":"","why_md":""}]` — นี่เป็นงานสร้างสรรค์ของเรา ไม่ใช่ของต้นฉบับ |
| `our_solution_author` * | enum | `ai_draft` / `human_verified` |
| `misconception_tags` * | string[] | ใช้ชื่อเดียวกับใน `pitfall` ของบทเรียน |
| `practice_template_ref` * | string หรือ null | `id` ของโจทย์ในฟีเจอร์ B ที่เป็นแนวเดียวกัน ใช้ทำปุ่ม "ฝึกแนวนี้" |
| `notes` | string หรือ null | เช่น "รูปในต้นฉบับอ่านไม่ชัด ต้องวาดใหม่" |

## 4. ต้องแก้อะไรให้ GPT

### 4.1 กฎที่ต้อง **เพิ่ม** ในทุกแชตที่คุยเรื่องข้อสอบจริง

วางข้อความนี้ต่อท้าย prompt ทุกครั้ง:

```
## กฎเรื่องข้อสอบจริง (ห้ามละเมิด)
- ห้ามสร้าง ห้ามนึก ห้ามเดา ตัวโจทย์ของข้อสอบจริงจากความจำของคุณ ไม่ว่ากรณีใด
- ใช้ได้เฉพาะข้อความที่ปรากฏในไฟล์หรือข้อความที่ผมแนบมาในแชตนี้เท่านั้น
- ถ้าส่วนใดในไฟล์อ่านไม่ออก ขาด หรือไม่มี ให้ใส่ null และเขียนใน notes ว่าอ่านไม่ได้
  ห้ามเติมข้อความให้ครบเอง ห้ามเดาตัวเลือกที่หายไป
- ถ้าผมขอข้อสอบจริงโดยไม่ได้แนบไฟล์ ให้ตอบว่าทำไม่ได้และขอไฟล์ ห้ามพยายามตอบ
- เฉลยและคำอธิบายให้เขียนขึ้นใหม่ด้วยภาษาของคุณเอง ห้ามคัดลอกเฉลยจากหนังสือหรือเว็บอื่น
```

### 4.2 กฎที่ต้อง **แก้** ในไฟล์ 06 (prompt แต่งโจทย์)

เดิมเขียนว่าโจทย์ทุกข้อต้อง `origin: "original"` — ยังใช้เหมือนเดิม **ไม่ต้องแก้**
แต่เพิ่มความชัดเจนว่า ฟีเจอร์ B กับ ฟีเจอร์ C แยกไฟล์กัน:
- `data/problems/` = โจทย์ที่แต่งใหม่ (`origin: "original"` เสมอ)
- `data/exams/` = ข้อสอบจริง (ฟอร์แมตในไฟล์นี้)
- **ห้ามเอาข้อสอบจริงไปใส่ใน `data/problems/`** เพราะระบบจะเอาไปสุ่มสร้างใหม่และอ้างว่าเป็นของตัวเอง

### 4.3 งานใหม่ 3 อย่างที่ GPT ทำได้ (prompt อยู่ข้อ 5)

| งาน | ได้อะไร |
|---|---|
| ถอดข้อสอบจากไฟล์ที่คุณมี → JSON | คลังข้อสอบจริงที่แสดงบนเว็บได้ |
| tag `topic_ids` + ให้ระดับความยากรายข้อ | ปุ่ม "ฝึกแนวนี้" + คาลิเบรตความยากของโจทย์ที่สร้างใหม่ |
| วิเคราะห์ผังการออกสอบย้อนหลัง | **แทนที่ `exam_weight.frequency` ที่เคยเดา ด้วยตัวเลขจริง** และได้ฟีเจอร์ "หัวข้อนี้ออกสอบ 8 ปีติด" |

> งานที่ 3 มีค่ามากที่สุดและไม่มีปัญหาลิขสิทธิ์เลย เพราะผลลัพธ์เป็นสถิติ ไม่ใช่ตัวข้อสอบ
> ถ้าคุณมีข้อสอบเก่าย้อนหลัง 5 ปี คุณจะบอกผู้ใช้ได้ว่า "เรื่องนี้ออก 5 ปีติด อ่านก่อน"
> ซึ่งเป็นสิ่งที่เด็กอยากรู้ที่สุดและไม่มีเว็บไหนตอบได้ด้วยข้อมูลจริง

## 4.4 สรุป: แต่ละงานต้องแนบไฟล์อะไรให้ GPT

| งาน | prompt | ไฟล์ที่ต้องแนบ | ต้องมีอะไรก่อน |
|---|---|---|---|
| ถอดข้อสอบ | ข้อ 5.1 | ไฟล์นี้ (09) + **ไฟล์ข้อสอบต้นฉบับ** | ไม่ต้องมีอะไรก่อน ทำได้เลย |
| tag หัวข้อ + เขียนเฉลย | ข้อ 5.2 | 09 + **03-schema.md** + **ผังหัวข้อวิชานั้น** | ต้องมีผังหัวข้อก่อน (สร้างด้วย 04) |
| วิเคราะห์ผังการออกสอบ | ข้อ 5.3 | 09 + JSON ที่ tag แล้วทุกปี | ต้องมีข้อมูลตั้งแต่ 3 ปีขึ้นไป |

**ทำไม 5.2 ต้องแนบ `03-schema.md` ด้วย** เพราะเกณฑ์ให้ระดับความยาก (ตาราง C.3) อยู่ในไฟล์นั้น
ไฟล์ 09 ไม่ได้คัดลอกตารางนั้นมาซ้ำ เพื่อให้มีที่มาที่เดียว ไม่ขัดกันเอง

**ลำดับที่ทำได้ตอนนี้** ถ้ายังไม่มีผังหัวข้อ ให้ทำ 5.1 (ถอดข้อสอบ) ไปก่อนได้เลย ไม่เสียเปล่า
แล้วค่อยกลับมาทำ 5.2 เมื่อผังหัวข้อเสร็จ

## 5. Prompt สำเร็จรูป

### 5.1 ถอดข้อสอบจากไฟล์ → JSON

```
คุณมีหน้าที่ "ถอดข้อความ" จากไฟล์ข้อสอบที่ผมแนบมา ไม่ใช่แต่งข้อสอบ
```

### 5.2 tag หัวข้อ + ให้ระดับความยาก + เขียนเฉลยของเราเอง

## 7. สิ่งที่ต้องมีบนเว็บสำหรับฟีเจอร์นี้

| สิ่งที่ต้องมี | เหตุผล |
|---|---|
| แสดงที่มาของข้อสอบทุกชุด (แหล่ง + วันที่ได้มา) | ความน่าเชื่อถือ และย้อนตรวจได้ |
| ป้ายบอกว่าชุดนี้ `raw` (ยังไม่เทียบต้นฉบับ) หรือ `checked` | ผู้ใช้ควรรู้ว่าอันไหนยังไม่ยืนยัน |
| แยกให้ชัดว่าอันไหน "ข้อสอบจริง" อันไหน "โจทย์ที่เราแต่ง" | ห้ามให้ผู้ใช้สับสน 2 อย่างนี้เด็ดขาด |
| ช่องทางแจ้งลบ (takedown) | ถ้ามีคนทักมาต้องปิดได้เร็ว |
| ปุ่ม "ฝึกแนวนี้" ที่ทุกข้อของข้อสอบจริง | จุดที่ฟีเจอร์ C ส่งผู้ใช้ไปฟีเจอร์ B |
