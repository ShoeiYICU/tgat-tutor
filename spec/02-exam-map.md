**หมายเหตุสำคัญเรื่อง TGAT1:** จำนวนตัวเลือก **ไม่เท่ากับ TGAT2**
TGAT1 เป็นปรนัย **4 ตัวเลือก** (`format: "mcq4"`) ส่วน TGAT2 เป็น **5 ตัวเลือก** (`mcq5`)
อย่าตั้งค่าตามกันเพราะเป็นวิชาในชุด TGAT เดียวกัน
และแม้ส่วนที่ 1 ชื่อ "ทักษะการพูด" แต่เป็นข้อสอบอ่านเลือกตอบทั้งหมด ไม่มีการพูดจริง

**หมายเหตุสำคัญเรื่อง TGAT3:** เป็นข้อสอบแบบ *สถานการณ์* (situational judgement)
ไม่มีเฉลยแบบคณิตศาสตร์ ให้ใช้ `format: "mcq4_tiered"` เป็นหลัก (ดู `03-schema.md` ข้อ C.8)
**ไม่ใช่ `mcq4`** เพราะผังสอบให้คะแนนลดหลั่น 0.25-1.00 ตัวเลือกหลายตัวเป็นคำตอบที่ยอมรับได้
ต่างกันที่ดีกว่าหรือด้อยกว่า ถ้าทำเป็นถูก/ผิดจะสอนผิดไปเลย
และ **`solution_steps` ต้องอธิบายเกณฑ์การตัดสิน** ไม่ใช่การคำนวณ

ผังสอบ TGAT3 มีรูปแบบข้อสอบที่สเปคยังรองรับไม่ได้ 1 แบบ คือ
**ข้อสอบ 2 ข้อที่สัมพันธ์กันและคะแนนผูกกัน** (อยู่ในส่วนที่ 1) — อย่าแต่งข้อแบบนี้จนกว่าจะเพิ่มฟิลด์

**ลำดับความสำคัญ: รอบที่ 1 — ทำก่อนทุกวิชา** เพราะผู้สมัคร TCAS ทุกคนต้องสอบ
ลำดับภายในรอบ: **TGAT2 -> TGAT1 -> TGAT3** (เหตุผลอยู่ในไฟล์ `08-workflow.md`)

> ลำดับการผลิตทั้งหมดที่ตัดสินใจแล้ว: **TGAT ครบ 3 พาร์ท -> TPAT ครบ 5 วิชา -> A-Level 16 วิชา**
> prompt พร้อมใช้ของทุกวิชาอยู่ในไฟล์ `10-prompt-pack.md`

### สิ่งที่ต้องรู้ก่อนแต่งโจทย์ A-Level

**จำนวนตัวเลือกไม่เท่ากันทุกวิชา**
- **mcq5** — คณิต 1, คณิต 2, วิทย์ประยุกต์, ฟิสิกส์, เคมี, ชีววิทยา, สังคมศึกษา, ภาษาไทย
- **mcq4** — ภาษาอังกฤษ และภาษาที่สามทั้ง 7 วิชา

**มีรูปแบบข้อสอบที่ไม่ใช่ปรนัยธรรมดาอยู่ 2 แบบ**
| รูปแบบ | วิชาที่มี | หมายเหตุ |
|---|---|---|
| ระบายคำตอบที่เป็นตัวเลข | คณิต 1, คณิต 2, ฟิสิกส์, เคมี | 5 ข้อ 25 คะแนน = **ข้อละ 5 คะแนน** ใช้ `format: "numeric"` |
| เลือกตอบเชิงซ้อน | ชีววิทยา (5 ข้อ 16 คะแนน), วิทย์ประยุกต์ (4 ข้อ 16.8 คะแนน) | ใกล้ `multi_select` ที่สุด แต่ **ผังสอบไม่ได้ระบุเกณฑ์ให้คะแนน** ห้ามเดา |

**ชั้นหัวข้อในผังมาจากไหน**
- ชั้น **ส่วน/สาระ** และชั้น **หัวข้อ** คัดจากผังสอบตรงตัว (ยกเว้นสังคมศึกษา ภาษาไทย
  และภาษาที่สาม ที่ผังสอบให้แต่ชื่อด้าน — ชั้นหัวข้อจึงเป็นการจัดกลุ่มเอง)
- ชั้น **leaf** เป็นการซอยของเราเองทุกวิชา เพราะผังสอบไม่ซอยย่อยกว่าชื่อหัวข้อ
- ทุก leaf มีหมายเหตุกำกับว่าเป็นการซอยเอง ไม่ใช่รายการทางการ
(คณิต 1 กับ คณิต 2 มีขอบเขตเนื้อหาไม่เท่ากัน — คณิต 2 ใช้เฉพาะสาระพื้นฐาน ต้องแยก topic tree ให้ชัด)

| `TPAT5` | ความถนัดครุศาสตร์-ศึกษาศาสตร์ | `tpat5` | **ยืนยันแล้ว** 100 ข้อ / 100 คะแนน / **180 นาที** / **ปรนัย 5 ตัวเลือก** — 2 ส่วนคะแนนเท่ากัน ส่วนละ 50 ข้อ 5 ด้าน **ด้านละ 10 ข้อพอดี** (พื้นฐานวิชาชีพครู: สื่อสาร / คิดวิเคราะห์ / เทคโนโลยีสารสนเทศ / เข้าใจตนเองและผู้อื่น / คิดเพื่อการเรียนรู้ · คุณลักษณะความเป็นครู: มนุษยสัมพันธ์ / ความรับผิดชอบ ซื่อสัตย์ ยุติธรรม / เข้าใจและยอมรับผู้อื่น / เรียนรู้และแบ่งปันความรู้ / ส่งเสริมความคิดสร้างสรรค์และภาวะผู้นำ) | ⭐⭐ | ☑ ผังหัวข้อเสร็จ |

**ลำดับความสำคัญ: รอบที่ 2** ลำดับภายในรอบ: **TPAT3 -> TPAT1 -> TPAT5 -> TPAT2 -> TPAT4**

**ยืนยันโครงสอบแล้ว 4 วิชา** (TPAT2 TPAT3 TPAT4 TPAT5) จาก mytcas.com/blueprint/
เหลือ **TPAT1 วิชาเดียวที่ยังยืนยันไม่ได้** ด้วยเหตุผลด้านล่าง

**หมายเหตุสำคัญเรื่อง TPAT3** (แก้ความเข้าใจผิดที่เคยเขียนไว้ในตารางนี้)
- ด้านที่สามคือ **"เชิงกลและฟิสิกส์"** ไม่ใช่ "เชิงกล-ไฟฟ้า" — ผังสอบไม่ได้พูดถึงไฟฟ้า
- ส่วนใหญ่เป็นข้อสอบ **ความถนัด** ไม่ใช่วิชาเนื้อหา (45 จาก 70 ข้อ) จึงใกล้ TGAT2 มากกว่า A-Level
- **ปรนัย 5 ตัวเลือก** เหมือน TGAT2 ไม่ใช่ 4 ตัวเลือกเหมือน TGAT1/TGAT3
- **180 นาที** ต่อ 70 ข้อ = ~2.6 นาทีต่อข้อ มากกว่า TGAT ถึงสองเท่าครึ่ง โจทย์จึงยาวและหลายขั้นได้
- ด้านตัวเลขและด้านมิติสัมพันธ์ **ทับกับ tgat2 แทบทั้งหมด** ผังใช้บทเรียนร่วมกันผ่าน `requires`
  ไม่สร้างหัวข้อซ้ำ (ดู `data/topics/tpat3.topics.json` หมายเหตุของ branch)
- ผังสอบ **ไม่ได้ให้รายการหัวข้อย่อย** มีแต่ตัวอย่างข้อสอบ หัวข้อ leaf ทั้งหมดจึงเป็น
  การอนุมานจากตัวอย่าง ไม่ใช่รายการทางการ
**หมายเหตุสำคัญเรื่อง TPAT1 — วิชานี้ติด ยังทำผังไม่ได้**

TPAT1 เป็นวิชาเดียวในกลุ่ม TGAT/TPAT ที่ **ยืนยันโครงสอบไม่ได้ด้วยเครื่องมือที่มี**
1. mytcas.com/blueprint/ **ไม่มีหน้าของ TPAT1** (ตรวจแล้ว มี TGAT1-3, TPAT2-5, A-Level ครบ)
   เพราะ กสพท เป็นผู้จัดสอบเอง ไม่ใช่ ทปอ.
2. เว็บ กสพท (`www9.si.mahidol.ac.th`) เข้าไม่ได้จากที่นี่
3. ประกาศ กสพท ที่หาได้ (`assets.mytcas.com/68/T68-COTMES-1.pdf` และ `-2.pdf`)
   เป็น **PDF สแกนเป็นภาพ (CCITT Fax)** ไม่มีข้อความให้ดึง และไม่มี OCR ในเครื่องมือที่มี

**กฎของโปรเจกต์ห้ามเดาโครงสอบเอง** (ข้อ 4 ในรายการกฎ) จึงหยุดไว้ที่นี่
ไฟล์ในคลัง `all_data/TPAT/TPAT1_10_วิชาเฉพาะ_กสพท/` เป็นชุดรวมจากชุมชน
**ไม่ใช่ประกาศทางการ** จึงใช้ยืนยันโครงสอบไม่ได้

**สิ่งที่จะปลดล็อกได้** (ทำอย่างใดอย่างหนึ่ง)
- ผู้ใช้ส่งประกาศ กสพท ฉบับล่าสุดมาเป็นไฟล์ที่อ่านข้อความได้ หรือบอกตัวเลขจากประกาศตรง ๆ
- ติดตั้ง OCR (เช่น `poppler-utils` + tesseract) แล้วอ่าน PDF สแกนที่ดาวน์โหลดไว้แล้ว
- หาหน้าเว็บทางการที่เป็นข้อความ (ไม่ใช่ภาพสแกน)

**แก้ความเข้าใจผิดเดิม: TPAT2 และ TPAT4 ไม่มีภาคปฏิบัติ**
เอกสารนี้เคยเขียนว่าสองวิชานี้มีส่วนที่ต้องวาดรูป **ซึ่งไม่ถูกต้อง**
ผังสอบทางการของทั้งสองวิชาระบุว่าเป็น **ปรนัยล้วน**
- TPAT2 ปรนัย 4 ตัวเลือก ทั้งสามส่วน (ทัศนศิลป์ ดนตรี นาฏศิลป์)
- TPAT4 ปรนัย 5 ตัวเลือก ทั้งสี่ส่วน

หัวข้อที่ฟังดูเป็นการปฏิบัติ เช่น "การเตรียมพร้อมร่างกายเพื่อปฏิบัตินาฏศิลป์"
หรือ "หลักในการปฏิบัติทักษะดนตรี" เป็นชื่อหัวข้อ **ความรู้** ที่ถามแบบปรนัย
ไม่ใช่การให้ลงมือทำจริง **ห้ามสร้างหัวข้อ "ฝึกวาดพร้อมเกณฑ์ให้คะแนนตัวเอง"**
เพราะไม่มีสิ่งนี้ในข้อสอบ

## ส่วน 4 — พื้นฐานสำหรับ "เรียนจาก 0" (สำคัญมากสำหรับฟีเจอร์ A)

คนที่เริ่มจาก 0 จริง ๆ มักพังเพราะพื้นฐาน **ม.ต้น** ไม่แน่น ไม่ใช่เพราะเนื้อหา ม.ปลาย ยาก
คลังเนื้อหาจึงต้องมีชั้นพื้นฐานรองรับด้วย โดย tag ด้วย `grade_band` ใน topic

| กลุ่ม | ต้องมีอะไร | ลำดับ |
|---|---|---|
| คณิต ม.ต้น | เศษส่วน ทศนิยม ร้อยละ อัตราส่วน เลขยกกำลัง สมการเชิงเส้น พาราโบลาเบื้องต้น ทฤษฎีบทพีทาโกรัส | ⭐⭐⭐ |
| วิทย์ ม.ต้น | หน่วย SI การแปลงหน่วย เลขนัยสำคัญ กราฟเบื้องต้น สมบัติสาร แรงและการเคลื่อนที่เบื้องต้น | ⭐⭐⭐ |
| อังกฤษพื้นฐาน | tense พื้นฐาน part of speech คำศัพท์ 2,000 คำแรก การอ่านจับใจความ | ⭐⭐⭐ |
| ไทยพื้นฐาน | ชนิดคำ ประโยค คำราชาศัพท์ การอ่านจับใจความ | ⭐⭐ |

> หัวข้อพื้นฐานพวกนี้อาจไม่ออกสอบตรง ๆ แต่ **ต้องมีในคลังเนื้อหา** และต้องถูกอ้างในฟิลด์ `requires`
> ของหัวข้อ ม.ปลาย เพื่อให้ระบบไต่หาต้นตอความไม่เข้าใจได้

## ส่วน 6 — คลังข้อสอบจริงย้อนหลัง (ฟีเจอร์ C)

ติดตามว่าแต่ละวิชามีข้อสอบจริงย้อนหลังกี่ปีแล้ว — ดูวิธีทำใน `09-real-exam-papers.md`

| exam_code | ปีที่มีไฟล์ต้นฉบับ | ถอดเป็น JSON แล้ว | คนเทียบต้นฉบับแล้ว | tag หัวข้อแล้ว | license_status | visibility |
|---|---|---|---|---|---|---|
| `TGAT2` | | | | | unknown | internal_only |
| `ALEVEL_61` | | | | | unknown | internal_only |
| `ALEVEL_64` | | | | | unknown | internal_only |
| `ALEVEL_65` | | | | | unknown | internal_only |
| `ALEVEL_66` | | | | | unknown | internal_only |

**เป้าหมายที่คุ้มที่สุด: ย้อนหลัง 5 ปี ต่อ 1 วิชา**
เพราะตั้งแต่ 3 ปีขึ้นไปจะเริ่มวิเคราะห์ได้ว่าหัวข้อไหนออกทุกปี
ซึ่งเปลี่ยน `exam_weight.frequency` ในผังหัวข้อจากตัวเลขที่เดา เป็นตัวเลขจริง (`confidence: "high"`)

แปลว่าใช้วิเคราะห์ภายในได้เต็มที่ แต่ยังไม่แสดงบนเว็บ
เปิดเป็น `public` เฉพาะชุดที่ยืนยันได้ว่าเป็น `official_public` (หน่วยงานเผยแพร่เอง)
