# วิธีเอาเว็บขึ้นออนไลน์ (ฟรี ไม่ต้องใช้บัตรเครดิต)

เว็บนี้เป็นไฟล์ HTML/JS/JSON ล้วน ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล จึงวางบนโฮสต์ฟรีได้ทันที
ขนาดทั้งโฟลเดอร์ประมาณ 12 MB แต่ผู้ใช้โหลดจริงครั้งละไม่กี่ร้อยกิโลไบต์ เพราะโหลดเฉพาะหัวข้อที่เปิด

---

## 1. ก่อนอัปโหลดทุกครั้ง

```powershell
cd D:\project\addmission
$env:PYTHONIOENCODING = "utf-8"
python scripts\build_content.py      # แปลงเนื้อหาใน content/ เป็นไฟล์ข้อมูล
python scripts\validate.py           # ต้องได้ "ต้องแก้: 0"
python scripts\render_template.py --stress   # ต้องได้ "ผ่านทั้งหมด"
python scripts\build_site.py         # สร้าง web/data/ ใหม่ทั้งหมด
```

ถ้าขั้นไหนไม่ผ่าน **อย่าเพิ่งอัปโหลด** เพราะแปลว่าเนื้อหามีข้อผิดพลาดค้างอยู่

## 2. ดูบนเครื่องตัวเองก่อน

```powershell
python -m http.server 8765 --directory web
```

เปิด http://localhost:8765 (เปิดไฟล์ `index.html` ตรง ๆ ไม่ได้ เพราะเบราว์เซอร์ห้ามอ่านไฟล์ JSON จากดิสก์)

ตรวจอย่างน้อย 4 หน้า: หน้าแรก · บทเรียนสักหัวข้อ · ฝึกโจทย์สักหัวข้อ · สอบเสมือนชุดสั้น

---

## 3. ทางที่ง่ายที่สุด: Netlify Drop (ไม่ต้องใช้ git)

1. เข้า https://app.netlify.com/drop แล้วสมัครฟรี (ใช้บัญชี Google หรือ GitHub ได้)
2. ลาก **โฟลเดอร์ `web` ทั้งโฟลเดอร์** ไปวางในกรอบ
3. ได้ลิงก์แบบ `ชื่อ.netlify.app` ทันที เปลี่ยนชื่อได้ที่ Site configuration → Change site name
4. เวลาจะอัปเดต: รัน build ใหม่ แล้วลากโฟลเดอร์ `web` ไปวางที่แท็บ Deploys ของเว็บเดิม

## 4. อีกทาง: GitHub Pages (เหมาะกับพอร์ต เพราะกรรมการเห็นโค้ดได้ด้วย)

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด **เฉพาะไฟล์ที่อยู่ในโฟลเดอร์ `web`** ขึ้นไปไว้ที่รากของ repository (รวมไฟล์ `.nojekyll` ที่มองไม่เห็นด้วย)
3. Settings → Pages → Source: Deploy from a branch → เลือก `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `ชื่อผู้ใช้.github.io/ชื่อrepo/`

> ถ้าอยากให้กรรมการเห็นทั้งโค้ดและเว็บ ให้ทำสอง repository แยกกัน: repo หนึ่งใส่โค้ดทั้งโปรเจกต์ (ยกเว้นข้อสอบจริง)
> อีก repo หนึ่งใส่เฉพาะไฟล์ในโฟลเดอร์ `web` สำหรับ GitHub Pages

---

## 5. ห้ามอัปโหลดเด็ดขาด

| ห้ามอัปโหลด | เหตุผล |
|---|---|
| `all_data/` | ไฟล์ข้อสอบจริงที่สะสมไว้ ไม่มีสิทธิ์เผยแพร่ |
| `data/exams/` | ข้อสอบจริงที่แปลงเป็นไฟล์แล้ว |
| `data/_generate/` | ไฟล์ทำงานภายใน |

ให้อัปโหลด **เฉพาะโฟลเดอร์ `web`** เท่านั้น ตัว `build_site.py` ถูกเขียนไม่ให้อ่านโฟลเดอร์ต้องห้ามเหล่านี้ตั้งแต่ต้น

## 6. เรื่องที่ลืมบ่อย

- **แก้ไฟล์ `app.js` หรือ `style.css` แล้วเบราว์เซอร์ยังเห็นของเก่า** ให้เพิ่มเลขท้าย `?v=` ในไฟล์ `web/index.html`
  (ตอนนี้เป็น `app.js?v=12` และ `style.css?v=9`) ทุกครั้งที่แก้ ไม่งั้นผู้ใช้เดิมจะยังเห็นเวอร์ชันเก่า
- **ลิงก์ที่เอาไปใส่พอร์ต** ควรเป็นหน้าแรก ไม่ใช่หน้าใดหน้าหนึ่ง เพราะหน้าแรกมีตัวเลขสรุปและทางเข้าครบ
- หน้า **เบื้องหลังการสร้าง** (`#/how`) คือหน้าที่เขียนไว้สำหรับกรรมการโดยเฉพาะ ถ้าต้องใส่ลิงก์เดียวในเอกสารพอร์ต
  ให้ใช้หน้าแรก แล้วบอกในเอกสารว่า "รายละเอียดเบื้องหลังอยู่ที่เมนูเบื้องหลัง"
- เว็บนี้ไม่เก็บข้อมูลผู้ใช้เลย ความคืบหน้าอยู่ในเบราว์เซอร์ของแต่ละคน จึงไม่ต้องมีนโยบายความเป็นส่วนตัวแบบยาว
